# 6장. 대상과 사건

> 이 장에서 배우는 것

> - `대상` 선언과 `사건` 선언

이 장의 기능은 AHAA 0.2에서 들어왔고, 0.5에서 사건 역할에 미지값을 쓸 수 있게 되었습니다(11장).

## 6.1 이론: 문장은 사건에 대한 서술이다

"유빈이 어제 복도에서 공을 굴렸다"라는 문장을 논리식으로 옮긴다고 해 봅시다. 가장 단순한 방법은 동사를 "굴리다(유빈, 공)"처럼 인자가 둘인 술어로 보는 것입니다. 그런데 "어제", "복도에서"를 덧붙이면 "굴리다(유빈, 공, 어제, 복도)"처럼 인자가 계속 늘어나고, 인자가 둘인 "굴리다"와 넷인 "굴리다"가 서로 다른 술어가 되어 버립니다. "유빈이 어제 복도에서 공을 굴렸다"가 참이면 "유빈이 공을 굴렸다"도 참이라는 당연한 추론조차 따로 규칙을 만들어야 합니다.

철학자 Donald Davidson은 1967년 논문 "The Logical Form of Action Sentences"에서 다른 방법을 제안했습니다. 행위 문장은 **사건 하나가 있다**는 주장이고, 수식어는 그 사건에 대한 추가 서술이라는 것입니다.

> 어떤 사건 e가 있다. e는 굴림이다. 그리고 e는 어제 일어났다. 그리고 e는 복도에서 일어났다.

이렇게 쓰면 수식어를 빼는 추론은 "그리고"의 한쪽을 버리는 것일 뿐이므로 자연스럽게 따라 나옵니다. Terence Parsons(1990, *Events in the Semantics of English*) 등은 이를 더 밀고 나가, 주어와 목적어까지 사건의 **역할**(thematic role)로 분리했습니다. 이를 **신-데이비드슨**(neo-Davidsonian) 분석이라고 합니다.

> 사건 e가 있다. e는 굴림이다. e의 행위자는 유빈이다. e의 대상은 공이다. e의 시간은 어제다. e의 장소는 복도다.

AHAA의 `사건`은 이 분석을 그대로 따릅니다. 사건은 이름이 있고, 역할들의 묶음입니다.

## 6.2 대상

사건에 참여하는 사람이나 사물은 `대상`으로 선언합니다.

```text
대상 이름
```

```aha
대상 유빈
대상 공
대상 화면
```

대상은 값의 한 종류(타입 `대상`)입니다. 대상끼리는 `==`, `!=`로 같은지만 비교할 수 있습니다. 대상에는 크기가 없으므로 `<` 같은 크기 비교는 `K304`입니다.

```aha 오류=K304
대상 공
대상 상자
검사 가 = 공 < 상자
```

## 6.3 사건 선언

```text
사건 이름: 역할 = 값, 역할 = 값, ...
```

```aha
기준 실험시계: 시간축
기준 복도: 위치축
대상 유빈
대상 공

사건 굴림: 주체 = 유빈, 대상 = 공, 시작 = 실험시계 @ 1 초, 종료 = 실험시계 @ 3 초, 출발 = 복도 @ 0 미터, 도착 = 복도 @ 150 센티미터
```

### 역할

| 역할 | 값의 타입 | 뜻 |
| --- | --- | --- |
| `주체` | 대상 | 행위를 하는 쪽 |
| `대상` | 대상 | 행위를 받는 쪽 |
| `관측자` | 대상 | 사건을 관측한 쪽 |
| `시작` | 시각 | 사건이 시작한 시각 (**필수**) |
| `종료` | 시각 | 사건이 끝난 시각 |
| `출발` | 위치 | 이동이 시작된 위치 |
| `도착` | 위치 | 이동이 끝난 위치 |

### 규칙

1. `시작`은 반드시 있어야 합니다. 시각이 없는 사건은 다른 사건과 순서를 따질 수 없기 때문입니다.
2. `종료`를 생략하면 시작과 같은 시각, 즉 한순간에 일어난 사건으로 봅니다.
3. `출발`과 `도착`은 함께 적거나 함께 생략합니다.
4. 시작과 종료는 같은 기준에, 출발과 도착은 같은 기준에 있어야 합니다(`K306`).
5. 종료는 시작보다 앞설 수 없습니다(`K402`). 시간은 거꾸로 흐르지 않으니까요. 반면 도착은 출발보다 "뒤쪽" 위치여도 됩니다. 물체는 뒤로도 움직일 수 있습니다.

```aha 오류=K312
기준 실험시계: 시간축
대상 공
사건 굴림: 대상 = 공
```

```text
예제.aha(3,4): error K312: 사건 '굴림'에는 '시작' 역할이 필요합니다.
```

```aha 오류=K402
기준 실험시계: 시간축
사건 굴림: 시작 = 실험시계 @ 2 초, 종료 = 실험시계 @ 1 초
```

```text
예제.aha(2,4): error K402: 사건 '굴림'의 종료(1000)가 시작(2000)보다 앞섭니다.
```

## 6.4 사건의 값 읽기

사건 이름 뒤에 `.`과 역할 이름을 붙이면 그 역할의 값을 읽습니다. 역할 외에 두 가지 **파생값**이 있습니다.

| 표현 | 뜻 | 타입 |
| --- | --- | --- |
| `사건.역할` | 그 역할의 값 | 역할의 타입 |
| `사건.소요` | 종료 − 시작 | 시간 |
| `사건.이동` | 도착 − 출발 | 거리 |

```aha
기준 실험시계: 시간축
기준 복도: 위치축
대상 유빈
대상 공

사건 굴림: 주체 = 유빈, 대상 = 공, 시작 = 실험시계 @ 1 초, 종료 = 실험시계 @ 3 초, 출발 = 복도 @ 0 미터, 도착 = 복도 @ 150 센티미터
사건 잡기: 주체 = 유빈, 시작 = 굴림.종료 + 200 밀리초

검사 순서 = 잡기.시작 - 굴림.종료 == 200 밀리초
검사 측정값 = 굴림.소요 == 2 초 그리고 굴림.이동 == 1500 밀리미터
검사 같은사람 = 굴림.주체 == 잡기.주체
검사 순간사건 = 잡기.종료 == 잡기.시작
```

`잡기`는 `종료`를 적지 않았으므로 순간 사건이고, 그래서 `잡기.종료 == 잡기.시작`이 참입니다.

사건 이름 자체는 값이 아닙니다. 사건은 역할들의 묶음이지 하나의 수가 아니기 때문입니다.

```aha 오류=K309
기준 실험시계: 시간축
사건 굴림: 시작 = 실험시계 @ 0 초
검사 가 = 굴림 == 굴림
```

```text
예제.aha(3,8): error K309: '굴림'은 사건이므로 값으로 쓸 수 없습니다. '굴림.시작'처럼 역할을 고르세요.
```

선언하지 않은 역할은 읽을 수 없습니다. 출발·도착이 없는 사건의 `이동`도 마찬가지입니다.

```aha 오류=K314
기준 실험시계: 시간축
사건 굴림: 시작 = 실험시계 @ 0 초
검사 가 = 굴림.이동 == 0 미터
```

```text
예제.aha(3,11): error K314: 사건 '굴림'에서 '이동'을 읽을 수 없습니다. 선언한 역할 또는 '소요'·'이동'을 사용하세요.
```

## 6.5 역할의 오류

| 실수 | 진단 |
| --- | --- |
| 같은 역할을 두 번 적음 | `K310` |
| 목록에 없는 역할 | `K311` |
| `시작` 없음, 출발·도착 중 하나만 있음 | `K312` |
| 역할의 타입이 맞지 않음 | `K313` |
| 시각 역할에 시간, 위치 역할에 거리를 줌 | `K307` |

```aha 오류=K311
기준 실험시계: 시간축
사건 굴림: 시작 = 실험시계 @ 0 초, 속도 = 3
```

```text
예제.aha(2,25): error K311: '속도'는 사건 역할이 아닙니다. 사용할 수 있는 역할: 주체, 대상, 관측자, 시작, 종료, 출발, 도착
```

```aha 오류=K307
기준 실험시계: 시간축
사건 굴림: 시작 = 1 초
```

```text
예제.aha(2,8): error K307: '시작' 역할에는 시각 값이 필요하지만 식은 시간입니다. 시각은 '기준 @ 1 초'처럼 시간축 기준 위에 놓아야 합니다.
```

역할 목록이 정해져 있는 것은 의도된 제한입니다. 역할을 자유롭게 만들 수 있으면 `시작`과 `시작시각`과 `개시`가 같은 뜻인지 컴파일러가 알 수 없습니다. 정해진 역할만 쓰면 모든 사건이 같은 방식으로 비교됩니다.

## 6.6 `사건` 선언과 문장

8장에서 배울 문장 문법을 쓰면 같은 사건을 한국어 문장으로 쓸 수 있습니다.

```text
사건 굴림: 주체 = 유빈, 대상 = 공, 시작 = 던짐
굴림: 유빈이 던짐에 공을 굴렸다
```

두 줄은 같은 내부 모델(사건과 역할)로 바뀝니다. `사건` 선언은 역할을 명시적으로 나열하는 방식이고, 문장은 조사로 역할을 나타내는 방식입니다. 11장에서 두 표기가 같은 판정을 내는지 확인합니다.

## 정리

- 사건은 이름과 역할들의 묶음입니다(신-데이비드슨 분석).
- 역할: 주체·대상·관측자(대상), 시작·종료(시각), 출발·도착(위치). 시작은 필수입니다.
- 종료를 생략하면 순간 사건입니다. 종료는 시작보다 앞설 수 없습니다.
- `사건.역할`, `사건.소요`, `사건.이동`으로 값을 읽습니다.

## 연습 문제

1. 신-데이비드슨 분석에서 "유빈이 복도에서 공을 굴렸다"로부터 "유빈이 공을 굴렸다"가 따라 나오는 이유를 설명해 보세요.
2. 1초에 시작해 1.5초 동안 진행된 회의를 사건으로 선언하고, 회의가 2초 이전에 끝났는지 검사해 보세요.
3. 유빈이 3초에 공을 던지고, 민수가 그로부터 400밀리초 뒤에 공을 잡았습니다. 두 사건을 선언하고 "던진 사람과 잡은 사람이 다르다"를 검사해 보세요.

<details>
<summary>풀이</summary>

1. 앞 문장은 "사건 e가 있고, e는 굴림이고, 행위자는 유빈, 대상은 공, 장소는 복도"이고, 뒷 문장은 여기서 "장소는 복도"를 뺀 것입니다. "A 그리고 B"에서 "A"를 추론하는 것은 논리의 기본 규칙이므로 별도의 규칙 없이 따라 나옵니다.

2. 회의는 1초에 시작해 1.5초 동안 진행되므로 2.5초에 끝납니다. 따라서 "2초 이전에 끝났다"는 검사는 거짓이고, 컴파일러는 `K401`을 냅니다.

```aha 오류=K401
기준 시계: 시간축
사건 회의: 시작 = 시계 @ 1 초, 종료 = 시계 @ 1 초 + 1500 밀리초
검사 일찍끝남 = 회의.종료 < 시계 @ 2 초
```

```text
예제.aha(3,4): error K401: 검사 '일찍끝남'의 결과가 거짓입니다.
```

이처럼 검사가 실패하는 것은 명세가 잘못되었다는 뜻이 아니라, **주장이 사실과 다르다**는 것을 컴파일러가 찾아낸 것입니다. 사실에 맞는 주장은 "2초 이후에 끝났다"입니다.

3. 두 사건과 검사는 다음과 같습니다. 2번의 올바른 검사도 함께 적었습니다.

```aha
기준 시계: 시간축
사건 회의: 시작 = 시계 @ 1 초, 종료 = 시계 @ 1 초 + 1500 밀리초
검사 늦게끝남 = 회의.종료 >= 시계 @ 2 초 그리고 회의.소요 == 1500 밀리초

대상 유빈
대상 민수
대상 공
사건 던짐: 주체 = 유빈, 대상 = 공, 시작 = 시계 @ 3 초
사건 잡음: 주체 = 민수, 대상 = 공, 시작 = 던짐.시작 + 400 밀리초
검사 다른사람 = 던짐.주체 != 잡음.주체
```
