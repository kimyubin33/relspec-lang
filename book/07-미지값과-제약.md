# 7장. 미지값과 제약

> 이 장에서 배우는 것
> - 아직 모르는 값을 `미지`로 선언하고 `조건`으로 범위를 좁히는 법
> - 목표의 네 가지 판정: 모순, 보장, 가능, 불가능
> - 이 판정을 정확하게 계산하는 이론: Simple Temporal Network
> - 최단 경로가 왜 "가장 빡빡한 상한"인지, 음의 순환이 왜 "모순"인지
> - `관측`으로 열린 값을 확정하는 법

이 장의 기능은 AHAA 0.3에서 들어왔습니다. 이 책에서 가장 수학적인 장이지만, 증명은 한 단계씩 풀어서 설명합니다.

## 7.1 모르는 값이 있는 명세

지금까지의 값은 모두 확정되어 있었습니다. 그러나 현실의 명세에는 모르는 값이 가득합니다. 사람이 버튼을 언제 누를지, 배양이 언제 끝날지, 택배가 언제 도착할지는 미리 알 수 없습니다. 대신 우리는 그 값에 대한 **제약**을 압니다. "자극 뒤에 누른다", "최대 200밀리초 안에 누른다" 같은 것들입니다.

AHAA는 모르는 값을 모르는 채로 두고, 제약들로부터 확실히 말할 수 있는 것만 정확히 계산합니다.

## 7.2 문법

| 문장 | 형식 | 뜻 |
| --- | --- | --- |
| 미지 | `미지 이름: 타입 = ?` | 값을 모르는 양을 선언합니다. |
| | `미지 이름: 시각 = 기준 @ ?` | 값을 모르는 점을 선언합니다. |
| 조건 | `조건 이름 = 논리식` | 모든 해가 따라야 하는 가정입니다. |
| 목표 | `목표 이름 = 논리식` | 판정할 주장입니다. 컴파일을 멈추지 않습니다. |
| 관측 | `관측 미지이름 = 값` | 미지값의 실제 값을 기록합니다. |

미지값의 타입은 `정수`, `시간`, `거리`, `시각`, `위치` 중 하나입니다. 시각과 위치는 기준 위의 점이므로 어느 기준인지 `기준 @ ?`로 밝힙니다.

```aha
기준 실험시계: 시간축
사건 자극: 시작 = 실험시계 @ 1000 밀리초

미지 반응: 시각 = 실험시계 @ ?
조건 반응은자극뒤 = 반응 >= 자극.시작
조건 지연상한 = 반응 - 자극.시작 <= 200 밀리초

목표 마감준수 = 반응 <= 실험시계 @ 1100 밀리초
목표 넉넉한마감 = 반응 <= 실험시계 @ 1500 밀리초
목표 너무이른마감 = 반응 < 자극.시작
```

```text
검사 통과 | 정의 0개, 검사 0개, 기준 1개, 사건 1개, 미지 1개, 조건·관측 2개, 목표 3개
미지 '반응': 1000 밀리초 ~ 1200 밀리초 (실험시계 기준)
목표 '마감준수': 가능 (보장 여부를 확정하려면 관측 필요: 반응)
목표 '넉넉한마감': 보장
목표 '너무이른마감': 불가능
```

## 7.3 해와 네 가지 판정

판정을 정확히 말하려면 **해**(solution)라는 개념이 필요합니다.

> **해**는 모든 미지값에 구체적인 값을 하나씩 정해 준 것 가운데, 모든 조건을 만족하는 것이다.

위 예에서 미지값은 `반응` 하나이고, 조건은 "1000 ≤ 반응"과 "반응 − 1000 ≤ 200"입니다. 그래서 반응 = 1000, 1001, ..., 1200이 해이고, 해는 모두 201개입니다. 판정은 이 해들의 모임에 대한 질문입니다.

| 판정 | 뜻 | 위 예에서 |
| --- | --- | --- |
| **모순** | 해가 하나도 없다 | 조건끼리 충돌하면 `K404` |
| **보장** | 목표가 **모든** 해에서 참이다 | 반응 ≤ 1500: 201개 모두 참 |
| **가능** | 목표가 **어떤** 해에서는 참이고 어떤 해에서는 거짓이다 | 반응 ≤ 1100: 1000~1100에서만 참 |
| **불가능** | 목표가 **어떤** 해에서도 참이 아니다 | 반응 < 1000: 어디서도 참이 아님 |

논리학의 말로 하면, 해 하나하나는 **가능 세계**(possible world)이고, 보장은 "모든 가능 세계에서 참"(필연), 가능은 "어떤 가능 세계에서 참"(가능)입니다. 양상 논리(modal logic)의 필연과 가능 개념과 같은 구조입니다.

해가 201개라면 하나씩 대입해 볼 수도 있습니다. 그러나 미지값이 10개이고 각각 범위가 1000이면 해의 후보는 1000의 10제곱, 즉 10³⁰개입니다. 우주의 나이를 나노초로 센 수(약 4×10²⁶)보다 많습니다. 하나씩 대입하는 방법은 불가능하고, 다른 방법이 필요합니다.

## 7.4 이론: 차이 제약과 그래프

### 차이 제약

AHAA가 지원하는 조건은 모두 다음 꼴로 바꿀 수 있습니다.

> **차이 제약**: x − y ≤ c (x, y는 미지값, c는 정수)

이 꼴 하나로 여러 표현을 나타낼 수 있습니다.

| 원래 조건 | 차이 제약으로 바꾸면 |
| --- | --- |
| x − y ≤ c | x − y ≤ c |
| x − y ≥ c | y − x ≤ −c |
| x − y == c | x − y ≤ c 그리고 y − x ≤ −c |
| x − y < c | x − y ≤ c − 1 (정수이므로) |
| x ≤ c (미지값 하나) | x − z ≤ c (z는 값이 0인 **원점**) |
| x ≥ c | z − x ≤ −c |

미지값 하나에 대한 조건은 값이 항상 0인 가상의 미지값 z(원점)를 도입해 차이로 만듭니다. 시각과 위치의 경우 z는 기준의 원점입니다. 엄격한 부등식 `<`를 `≤ c − 1`로 바꿀 수 있는 것은 모든 값이 정수(밀리초, 밀리미터)이기 때문입니다(3장).

### 제약을 그래프로

이제 핵심 아이디어입니다. 각 미지값을 **꼭짓점**으로, 제약 x − y ≤ c를 **y에서 x로 가는 가중치 c인 간선**으로 그립니다.

```text
x − y ≤ c   ⟺   y ──c──▶ x
```

이렇게 만든 그래프를 **Simple Temporal Network**(STN)라고 합니다. Rina Dechter, Itay Meiri, Judea Pearl이 1991년 논문 "Temporal Constraint Networks"(*Artificial Intelligence* 49권)에서 시간 추론을 위해 정리한 모형입니다. 같은 기법이 알고리즘 교과서(Cormen 외, *Introduction to Algorithms*)에는 "차이 제약과 최단 경로"라는 이름으로 실려 있습니다.

### 정리 1: 최단 경로는 가장 빡빡한 상한이다

> y에서 x로 가는 최단 경로의 길이를 d(y, x)라 하면, 모든 해에서 x − y ≤ d(y, x)이고, 이 값에 정확히 도달하는 해가 있다.

**왜 상한인가.** y에서 x로 가는 경로 y → a → b → x가 있다고 합시다. 간선마다 제약이 있습니다.

```text
a − y ≤ c₁
b − a ≤ c₂
x − b ≤ c₃
```

세 부등식을 더하면 가운데 항들이 서로 지워집니다(망원경처럼 접힌다고 해서 **망원 합**이라고 부릅니다).

```text
(a − y) + (b − a) + (x − b) = x − y ≤ c₁ + c₂ + c₃
```

즉 **어떤 경로든 그 길이는 x − y의 상한**입니다. 상한이 여러 개 있으면 가장 작은 것이 가장 빡빡하므로, 최단 경로의 길이가 가장 빡빡한 상한입니다.

**왜 정확히 도달하는가.** 해 집합이 비어 있지 않을 때, 각 미지값 v에 "y에서 v까지의 최단 거리" d(y, v)를 값으로 주면 그것이 하나의 해가 됩니다. 간선 a → b(가중치 c)마다 최단 거리의 성질 d(y, b) ≤ d(y, a) + c가 성립하는데, 이것이 바로 제약 b − a ≤ c를 만족한다는 뜻이기 때문입니다. 이 해에서 x − y = d(y, x) − 0 = d(y, x)이므로 상한에 정확히 도달합니다. (원점처럼 값이 고정된 꼭짓점이 있으면 거기에 맞게 전체를 평행 이동합니다. 차이 제약은 모든 값에 같은 수를 더해도 그대로 성립하기 때문에 가능합니다.)

### 정리 2: 음의 순환은 모순이다

> 그래프에 길이의 합이 음수인 순환이 있으면 해가 없고, 없으면 해가 있다.

**음의 순환이 있으면 해가 없다.** 순환 x → a → x를 따라 망원 합을 하면 왼쪽은 x − x = 0이 됩니다. 그래서 0 ≤ (순환의 길이)라는 부등식이 나옵니다. 순환의 길이가 음수이면 0 ≤ 음수라는 거짓이므로 어떤 값으로도 만족할 수 없습니다.

**음의 순환이 없으면 해가 있다.** 이때는 최단 거리가 잘 정의되고(음의 순환을 돌며 끝없이 줄어드는 일이 없으므로), 정리 1의 증명처럼 최단 거리로 값을 정하면 해가 됩니다.

### 손으로 풀어 보기

세 단계로 된 실험을 생각해 봅시다. 가에 시작해, 1~3초 뒤 나 단계가 오고, 그로부터 2~4초 뒤 다 단계가 오며, 전체는 5초를 넘지 않습니다. 가는 시계 원점에서 관측되었습니다.

```aha
기준 시계: 시간축
미지 가: 시각 = 시계 @ ?
미지 나: 시각 = 시계 @ ?
미지 다: 시각 = 시계 @ ?
관측 가 = 시계 @ 0 초
조건 첫단계 = 나 - 가 >= 1 초 그리고 나 - 가 <= 3 초
조건 둘째단계 = 다 - 나 >= 2 초 그리고 다 - 나 <= 4 초
조건 전체 = 다 - 가 <= 5 초
목표 빠듯 = 다 - 가 <= 4 초
목표 넉넉 = 다 - 가 >= 3 초
목표 너무짧음 = 다 - 가 < 3 초
```

간선을 정리하면 다음과 같습니다(단위 초).

```text
가 ──3──▶ 나      (나 − 가 ≤ 3)
나 ──(−1)──▶ 가   (가 − 나 ≤ −1, 즉 나 − 가 ≥ 1)
나 ──4──▶ 다      (다 − 나 ≤ 4)
다 ──(−2)──▶ 나   (나 − 다 ≤ −2, 즉 다 − 나 ≥ 2)
가 ──5──▶ 다      (다 − 가 ≤ 5)
```

**다 − 가의 최댓값**은 가에서 다로 가는 최단 경로입니다. 경로는 두 개입니다.

- 가 → 나 → 다: 3 + 4 = 7
- 가 → 다: 5

최단은 5이므로 다 − 가 ≤ 5초입니다. "각 단계의 최대를 더하면 7초"이지만 전체 제한 때문에 5초가 진짜 상한입니다.

**다 − 가의 최솟값**은 "가 − 다의 최댓값"에 음수를 붙인 것입니다. 다에서 가로 가는 최단 경로는 다 → 나 → 가: (−2) + (−1) = −3이므로, 가 − 다 ≤ −3, 즉 다 − 가 ≥ 3초입니다.

그래서 다는 3~5초 사이입니다. 컴파일러의 답과 같습니다.

```text
미지 '가': 0 밀리초 ~ 0 밀리초 (시계 기준) · 관측됨
미지 '나': 1000 밀리초 ~ 3000 밀리초 (시계 기준)
미지 '다': 3000 밀리초 ~ 5000 밀리초 (시계 기준)
목표 '빠듯': 가능 (보장 여부를 확정하려면 관측 필요: 다)
목표 '넉넉': 보장
목표 '너무짧음': 불가능
```

## 7.5 판정 알고리즘

### 모든 쌍의 최단 거리

컴파일러는 모든 꼭짓점 쌍의 최단 거리를 표(행렬) D로 유지합니다. D[y][x]는 x − y의 가장 빡빡한 상한이며, 경로가 없으면 상한이 없습니다(∞). 모든 쌍의 최단 거리를 구하는 고전적인 방법이 **Floyd–Warshall 알고리즘**(1962)입니다. 꼭짓점이 n개일 때 n³에 비례하는 시간이 걸립니다.

### 조건을 하나씩 더하기

AHAA는 조건을 파일에 적힌 순서대로 하나씩 더합니다. 새 간선 u → v(가중치 w)를 더할 때 D를 처음부터 다시 계산할 필요는 없습니다.

1. **모순 확인:** D[v][u] + w < 0이면 v에서 u로 돌아오는 경로와 새 간선이 음의 순환을 만듭니다. 이 조건이 앞선 조건들과 모순이므로 `K404`를 냅니다.
2. **갱신:** 모순이 아니면 모든 쌍 (i, j)에 대해 새 간선을 지나는 경로가 더 짧은지 봅니다.

```text
D[i][j] ← min( D[i][j],  D[i][u] + w + D[v][j] )
```

간선 하나를 더할 때 n² 칸만 보면 되므로 조건 하나에 n²에 비례하는 시간이 듭니다. 이 방식은 **어느 조건에서 모순이 생겼는지** 정확히 알려 줄 수 있다는 장점도 있습니다.

```aha 오류=K404
미지 가: 시간 = ?
미지 나: 시간 = ?
조건 하나 = 가 - 나 >= 5 초
조건 둘 = 나 - 가 >= 1 초
```

```text
예제.aha(4,4): error K404: 조건 '둘'이 앞선 조건·관측과 모순됩니다. 앞선 조건: '가 - 나' 최소 5000 밀리초. 이 조건: '가 - 나' 최대 -1000 밀리초.
```

### 목표 판정

목표도 차이 제약 몇 개의 `그리고`로 바뀝니다. 각 제약을 to − from ≤ c라 하면 다음과 같이 판정합니다.

1. **보장:** 모든 제약에서 D[from][to] ≤ c이면 보장입니다. 가장 빡빡한 상한이 이미 c 이하이므로 모든 해에서 성립합니다(정리 1).
2. **가능:** 보장이 아니면, D를 복사한 뒤 목표의 제약들을 조건처럼 더해 봅니다. 모순이 없으면 목표를 만족하는 해가 있으므로 가능입니다(정리 2).
3. **불가능:** 더하다가 모순이 생기면 불가능입니다.

### 범위

미지값 x의 범위는 원점 z와의 최단 거리로 바로 얻습니다.

```text
최댓값 = D[z][x]        (x − z의 상한)
최솟값 = −D[x][z]       (z − x의 상한에 음수를 붙임)
```

경로가 없으면 그쪽 경계가 없습니다. 출력에서는 "상한 없음", "하한 없음"으로, 중간 표현(JSON)에서는 `null`로 나타냅니다.

```aha
기준 복도: 위치축
미지 공위치: 위치 = 복도 @ ?
조건 앞쪽 = 공위치 >= 복도 @ 2 미터
```

```text
미지 '공위치': 2000 밀리미터 ~ 상한 없음 (복도 기준)
```

### 정수 해

모든 가중치가 정수이면 최단 거리도 정수이므로, 정리 1의 증명에서 만든 해도 정수입니다. 그래서 "정수 밀리초 해가 있는가"와 "실수 해가 있는가"의 답이 같고, 엄격한 부등식을 `≤ c − 1`로 바꾸는 것이 정당합니다.

## 7.6 관측

`관측`은 미지값의 실제 값을 기록합니다. 내부적으로는 "x = 값"이라는 조건이지만, 조건과 따로 기록됩니다. 규칙(조건)과 측정(관측)은 성격이 다르기 때문입니다.

```aha
기준 실험시계: 시간축
사건 자극: 시작 = 실험시계 @ 1000 밀리초
미지 반응: 시각 = 실험시계 @ ?
조건 반응은자극뒤 = 반응 >= 자극.시작
조건 지연상한 = 반응 - 자극.시작 <= 200 밀리초
목표 마감준수 = 반응 <= 실험시계 @ 1100 밀리초
관측 반응 = 실험시계 @ 1080 밀리초
```

```text
미지 '반응': 1080 밀리초 ~ 1080 밀리초 (실험시계 기준) · 관측됨
목표 '마감준수': 보장
```

관측 전에 "가능"이던 목표가 관측 후 "보장"이 되었습니다. 7.2의 출력에서 컴파일러가 "보장 여부를 확정하려면 관측 필요: 반응"이라고 알려 준 바로 그 관측입니다. 이 목록은 목표에 등장하는 미지값 가운데 아직 관측되지 않았고, 조건만으로 값이 하나로 정해지지도 않은 것들입니다(0.6부터. 0.5에서는 조건으로 값이 정해진 미지값도 목록에 나왔습니다).

관측이 규칙과 충돌하면 `K404`입니다. 측정이 틀렸거나, 규칙이 틀렸거나 둘 중 하나라는 신호입니다.

```aha 오류=K404
기준 실험시계: 시간축
사건 자극: 시작 = 실험시계 @ 1000 밀리초
미지 반응: 시각 = 실험시계 @ ?
조건 지연상한 = 반응 - 자극.시작 <= 200 밀리초 그리고 반응 >= 자극.시작
관측 반응 = 실험시계 @ 1300 밀리초
```

```text
예제.aha(5,4): error K404: 관측 '반응'이 앞선 조건·관측과 모순됩니다. 앞선 조건: '반응' 최대 실험시계 @ 1200 밀리초. 이 관측: '반응' 최소 실험시계 @ 1300 밀리초.
```

관측에는 몇 가지 규칙이 있습니다.

- 미지값만 관측할 수 있고, 같은 미지값은 한 번만 관측합니다(`K407`).
- 관측값의 타입과 기준은 미지값과 같아야 합니다(`K303`, `K307`, `K306`).
- 관측값에는 다른 미지값을 쓸 수 없습니다(`K406`).

## 7.7 미지값이 들어간 검사

`검사`는 "반드시 참"이라는 뜻이었습니다. 미지값이 들어가면 이것은 **모든 해에서 참**, 즉 보장을 뜻합니다. 가능에 그치면 `K403`입니다.

```aha 오류=K403
기준 시계: 시간축
미지 가: 시각 = 시계 @ ?
조건 상한 = 가 <= 시계 @ 5 초
검사 엄격 = 가 <= 시계 @ 3 초
```

```text
예제.aha(4,4): error K403: 검사 '엄격'은 모든 해에서 보장되지 않습니다: 일부 해에서만 성립합니다. 보장 여부를 확정하려면 관측이 필요합니다: 가.
```

`목표`와 `검사`의 차이를 정리하면 다음과 같습니다.

| | 목표 | 검사 |
| --- | --- | --- |
| 판정을 기록 | 보장·가능·불가능 중 하나 | 보장이어야 통과 |
| 컴파일을 멈춤 | 아니요 | 보장이 아니면 멈춤 |
| 쓰임 | "이것이 성립할까?"를 묻기 | "이것은 반드시 성립해야 한다"를 강제하기 |

판정은 파일의 모든 조건과 관측을 읽은 뒤에 합니다. 그래서 목표나 검사가 그보다 뒤에 적힌 조건의 영향도 받습니다.

## 7.8 지원 범위와 그 이유

AHAA는 "미지값 하나의 상·하한"과 "두 미지값의 차이의 상·하한"을 `그리고`로 묶은 것만 지원합니다. 그 밖의 것은 `K405`로 거절합니다.

| 표현 | 진단 | 이유 |
| --- | --- | --- |
| `가 != 1 초` | `K405` | "1초보다 작거나 크다"는 `또는`입니다. |
| `가 < 1 초 또는 나 < 1 초` | `K405` | `또는` |
| `가 + 나 <= 1 초` | `K405` | 차이가 아니라 합입니다. |
| `2 * 가 <= 1 초` | `K405` | 계수가 1이 아닙니다. |
| `가 * 나 <= 1` | `K405` | 비선형입니다. |

```aha 오류=K405
미지 가: 시간 = ?
미지 나: 시간 = ?
조건 합 = 가 + 나 <= 1 초
```

```text
예제.aha(3,14): error K405: 지원하는 제약은 미지값 하나의 상·하한 또는 두 미지값의 차이(가 - 나)에 대한 상·하한입니다.
```

**`또는`을 지원하지 않는 이유.** `또는`이 들어간 시간 제약 문제(Temporal CSP, Disjunctive Temporal Problem)는 일반적으로 **NP-완전**입니다. Dechter·Meiri·Pearl의 같은 논문에서 보였듯이, 조건마다 "이 구간 또는 저 구간"을 고를 수 있으면 해를 찾는 데 경우의 수를 모두 따져야 할 수 있습니다. `또는`이 k개면 최악의 경우 2ᵏ가지 조합을 살펴야 합니다. 반면 STN은 n³ 이하의 시간에 정확히 풀립니다. AHAA는 먼저 "빠르고 정확하게 풀리는 영역"을 완성했고, `또는`은 별도 단계로 남겨 두었습니다.

**합을 지원하지 않는 이유.** x + y ≤ c는 그래프의 간선 하나로 나타낼 수 없습니다. 이런 제약을 다루려면 선형 계획법(linear programming) 같은 더 일반적인 도구가 필요합니다. 그 도구들은 차이 제약보다 느리고, 정수 해를 요구하면 일반적으로 NP-어려운 문제가 됩니다.

## 7.9 판정이 맞다는 것을 어떻게 아는가

컴파일러 저장소의 `tests/solver_bruteforce.rs`는 임의의 제약 600세트를 만들어, 미지값 세 개를 −3~3 범위에서 **모든 조합을 대입**한 결과와 컴파일러의 판정을 비교합니다. 보장·가능·불가능 판정과 모순 여부, 모든 미지값의 최솟값·최댓값이 하나도 빠짐없이 일치해야 시험을 통과합니다. 7.3에서 하나씩 대입하는 방법은 큰 문제에는 쓸 수 없다고 했지만, 작은 문제에서 빠른 방법을 검증하는 데에는 훌륭한 기준이 됩니다.

## 7.10 오류 정리

| 코드 | 상황 |
| --- | --- |
| `K403` | 미지값이 들어간 검사가 보장되지 않음 |
| `K404` | 조건·관측이 모순되거나, 조건이 항상 거짓 |
| `K405` | 지원 범위 밖의 제약 |
| `K406` | 정의, 관측값에 미지값을 씀 |
| `K407` | 미지값이 아닌 것을 관측하거나 두 번 관측함 |

```aha 오류=K406
미지 가: 시간 = ?
정의 나: 시간 = 가 + 1 초
```

```text
예제.aha(2,4): error K406: 정의 '나'에 미지값이 들어 있습니다. 정의에는 값이 확정된 식만 쓸 수 있습니다.
```

`정의`는 확정된 값을 위한 것이므로 미지값을 쓸 수 없습니다. 미지값에 대한 관계는 `조건`으로 적습니다.

## 정리

- **해**는 모든 조건을 만족하는 값의 할당입니다. 판정은 해들의 모임에 대한 질문입니다.
- 조건은 **차이 제약** x − y ≤ c로 바뀌고, 그래프의 간선이 됩니다(STN).
- 최단 경로 = 가장 빡빡한 상한, 음의 순환 = 모순입니다.
- 목표는 보장(모든 해), 가능(일부 해), 불가능(어떤 해도 아님)으로 판정됩니다.
- `관측`은 미지값을 확정하며, 가능을 보장이나 불가능으로 바꿀 수 있습니다.
- `또는`, 합, 계수는 NP-완전성과 표현 범위 때문에 현재 거절합니다.
