# 부록 A. 진단 코드 전체

RelSpec 0.6 컴파일러가 내는 모든 진단 코드입니다. 메시지에 들어가는 낱말 뒤의 조사는 받침에 맞게 바뀝니다('실험시계'는, '유빈'은). 진단의 형식은 `파일(줄,열): error 코드: 메시지`이며(2장), 컴파일러는 첫 번째 진단에서 멈춥니다.

코드의 첫 자리는 진단이 나오는 단계를 나타냅니다.

| 범위 | 단계 |
| --- | --- |
| K1xx | 어휘 분석: 글자를 토큰으로 나눌 때 |
| K2xx | 구문 분석: 토큰을 문장 구조로 묶을 때 |
| K3xx | 의미 분석: 이름과 타입을 확인할 때 |
| K4xx | 판정: 검사와 제약을 평가할 때 |
| K5xx | 문장 문법과 정도: 한국어 문장, 참조, 정도, 시제, 규칙 |

## K1xx 어휘

| 코드 | 뜻 | 대표 원인 | 장 |
| --- | --- | --- | --- |
| K100 | 알 수 없는 기호 | `/`, `&`, 단독 `!` | 3장 |
| K101 | 한 줄의 토큰이 128개를 넘음 | 지나치게 긴 식 | 3장 |

## K2xx 구문

| 코드 | 뜻 | 대표 원인 | 장 |
| --- | --- | --- | --- |
| K200 | 문법 오류 | 콜론·등호 누락, 예약어를 이름으로 씀, 한 줄에 두 문장, 빈 참조 본문, 잘못된 미지값 선언 형식, 규칙에 `이면`이 없거나 방식이 `최소로`·`곱으로`가 아님 | 3, 4, 7, 9, 13장 |
| K201 | 문장이 하나도 없음 | 빈 파일, 주석만 있는 파일 | 3장 |

## K3xx 이름과 타입

| 코드 | 뜻 | 대표 원인 | 장 |
| --- | --- | --- | --- |
| K301 | 같은 이름을 두 번 선언 | 정의·검사·대상·사건·문장 이름이 겹침, 행위를 두 번 선언 | 3장 |
| K302 | 선언하지 않은 이름을 씀 | 선언보다 앞에서 참조, 오타 | 4장 |
| K303 | 선언한 타입과 식의 타입이 다름 | `정의 가: 시간 = 3`, 검사가 논리가 아님, 규칙의 전제·강도의 타입 | 4, 13장 |
| K304 | 연산에 맞지 않는 타입 조합 | 시간 + 거리, 시간 × 시간, 대상 < 대상, 연쇄 비교 | 4장 |
| K305 | 기준 위의 점끼리 더함 | 시각 + 시각, 시간 − 시각 | 5장 |
| K306 | 서로 다른 기준의 값을 섞음 | 실험시계의 시각 − 영상시계의 시각 | 5장 |
| K307 | 점과 양의 혼동 | 시각 자리에 시간, 시각과 시간을 비교 | 5장 |
| K308 | `@`의 잘못된 사용 | `@` 앞이 기준이 아님, 시간축에 거리 | 5장 |
| K309 | 기준이나 사건을 값처럼 씀 | `실험시계 == 실험시계`, `굴림 == 굴림` | 5, 6장 |
| K310 | 사건에 같은 역할을 두 번 적음 | `시작 = ..., 시작 = ...` | 6장 |
| K311 | 알 수 없는 역할 | 사건의 `속도`, 행위 선언의 없는 역할 | 6, 8장 |
| K312 | 사건의 필수 역할 누락 | `시작` 없음, 출발·도착 중 하나만 있음 | 6장 |
| K313 | 사건 역할의 타입이 맞지 않음 | `주체 = 3` | 6장 |
| K314 | 읽을 수 없는 역할 | 선언하지 않은 역할, 출발·도착 없는 `이동`, 종료 없는 문장의 `소요` | 6, 11장 |

## K4xx 판정

| 코드 | 뜻 | 대표 원인 | 장 |
| --- | --- | --- | --- |
| K401 | 검사가 거짓 | 주장이 사실과 다름 | 2, 4장 |
| K402 | 종료가 시작보다 앞섬 | 확정된 시각의 역전, 또는 앞선 조건 때문에 반드시 역전됨 | 6, 11장 |
| K403 | 미지값이 든 검사가 보장되지 않음 | 일부 해에서만 성립 | 7장 |
| K404 | 조건·관측이 모순되거나 항상 거짓 | STN의 음의 순환 | 7장 |
| K405 | 지원 범위 밖의 제약 | `!=`, `또는`, 미지값의 합·배수·곱 | 7장 |
| K406 | 확정값이 필요한 곳에 미지값 | 정의, 관측값 | 7장 |
| K407 | 잘못된 관측 | 미지값이 아닌 것을 관측, 두 번 관측 | 7장 |

| 코드 | 뜻 | 대표 원인 | 장 |
| --- | --- | --- | --- |
| K500 | 문장 구조 오류 | 행위로 끝나지 않음, 문장에 `=` 같은 기호, 참조 괄호가 끝에 있지 않음 | 8, 9장 |
| K501 | 알 수 없는 낱말 | 선언하지 않은 이름, 조사가 없는 이름 | 8장 |
| K502 | 조사 형태가 받침과 맞지 않음 | `유빈가`, `연필으로` | 8장 |
| K503 | 선언되지 않은 행위 | 행위 선언 누락, 알아볼 수 없는 불규칙 활용 | 8장 |
| K504 | 행위의 필수 역할 누락 | 주체 없는 문장, 대상 없는 '설계하다' | 8장 |
| K505 | 문장에 같은 역할이나 정도가 두 번 | `유빈이 유빈이`, `10% 20%` | 8, 10장 |
| K506 | 조사와 값의 타입이 맞지 않음 | 대상에 '에', 시각에 '을' | 8장 |
| K507 | 활용형이 여러 행위와 맞음 | 같은 활용형을 두 행위가 공유 | 8장 |
| K510 | 지시어가 가리키는 참조가 없음 | `이렇게`만 쓰고 `(참조 N)` 없음 | 9장 |
| K511 | 정의되지 않은 참조를 인용 | `(참조 2)`인데 `참조 2:` 없음 | 9장 |
| K512 | 같은 참조 번호를 두 번 정의 | `참조 1:` 두 줄 | 9장 |
| K520 | 정도가 0~100%를 벗어남 | `150%` | 10장 |
| K530 | 시제와 시각이 맞지 않음 | 지금 이전의 사건을 미래형으로 | 11장 |
| K540 | 검사가 규칙의 계산 방식에 따라 참·거짓으로 갈림 | 방식을 정하지 않은 규칙의 결과를 한 방식에서만 성립하는 기준과 비교 | 13장 |
| K541 | 방식에 따라 갈라지는 값을 쓸 수 없는 곳 | 조건에 규칙의 결과를 씀, 한 판정에 미지값과 규칙의 결과를 함께 씀 | 13장 |
| K542 | 방식의 조합이 4096가지를 넘음 | 방식을 정하지 않은 규칙이 13개 이상 이어짐 | 13장 |

## 오류를 고치는 순서

컴파일러는 첫 오류에서 멈추므로, 맨 위에 보고된 오류부터 고치고 다시 실행하는 것이 가장 빠릅니다. 오류 하나가 다른 오류처럼 보이는 경우가 있습니다. 예를 들어 `정의`를 빠뜨린 줄은 문장으로 읽혀 `K500`이 나옵니다. 메시지가 이상하게 느껴지면 그 줄이 어떤 키워드로 시작하는지부터 확인하세요.
