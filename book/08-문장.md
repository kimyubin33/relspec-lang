# 8장. 문장

> 이 장에서 배우는 것
> - 키워드 없이 한국어 문장으로 사건을 쓰는 법
> - 조사가 역할을 정하는 원리와 조사 형태 규칙
> - 행위(동사)와 필수 역할(논항 구조)
> - 컴파일러가 "설계했다"를 "설계하다"로 알아보는 방법
> - 자연어처럼 보이지만 엄격한 언어, 통제 자연어

**AHAA에서 이 장의 자리 (잇는다: 문장).** 낱말과 낱말을 잇는 주된 방법입니다. 장면에 적은 낱말이 무엇을 하는지, 무엇과 어떤 관계인지를 문장으로 적습니다. 꼭 있어야 하는 역할이 빠지면 거절합니다.

이 장의 기능은 AHAA 0.4에서 들어왔습니다.

## 8.1 문장 한 줄이 사건 하나

6장의 `사건` 선언은 역할을 직접 나열했습니다. 같은 내용을 한국어 문장으로 쓸 수 있습니다.

```aha
기준 실험시계: 시간축
대상 유빈
대상 공
정의 던짐: 시각 = 실험시계 @ 1 초
행위 굴리다: 주체, 대상

유빈이 던짐에 공을 굴렸다
```

키워드(`정의`, `사건` 등)로 시작하지 않는 줄은 **문장**입니다. (문장 가운데에 `-면`으로 끝나는 행위가 있으면 규칙을 말하는 조건문이 됩니다. 조건문은 14장에서 다룹니다.) 문장은 다음 규칙으로 읽힙니다.

1. **마지막 낱말은 행위(동사)**입니다. 한국어는 동사가 문장 끝에 오는 언어(SOV 어순)이기 때문입니다.
2. **나머지 낱말은 "이름 + 조사"**입니다. 조사가 그 이름이 사건에서 맡는 역할을 정합니다.
3. 문장 하나는 사건 하나로 바뀝니다. 위 문장은 "주체 = 유빈, 대상 = 공, 시작 = 던짐인 굴리다 사건"입니다.

## 8.2 이론: 통제 자연어

자연어는 모호합니다. "유빈이 민수에게 공을 던진 사람을 소개했다"에서 공을 던진 사람이 누구인지는 문맥 없이는 알 수 없습니다. 반대로 프로그래밍 언어는 엄격하지만, 배우지 않은 사람은 읽기 어렵습니다.

**통제 자연어**(controlled natural language)는 그 중간을 노립니다. 자연어의 모습은 유지하되 어휘와 문법을 제한해서, 모든 문장이 **정확히 하나의 뜻**으로만 읽히게 만든 언어입니다. 대표적인 예가 취리히 대학에서 1990년대 중반부터 개발한 **Attempto Controlled English**(ACE)입니다. ACE로 쓴 영어 문장은 영어 화자가 읽을 수 있으면서도, 컴퓨터가 논리식으로 정확히 바꿀 수 있습니다. 항공기 정비 매뉴얼에 쓰이는 ASD Simplified Technical English처럼, 오해가 사고로 이어지는 분야에서도 비슷한 생각이 쓰입니다.

AHAA의 문장 문법은 한국어 통제 자연어입니다. 제한은 다음과 같습니다.

- 모든 낱말은 미리 선언된 이름이어야 합니다. 모르는 낱말을 추측하지 않습니다.
- 모든 이름에는 역할을 나타내는 조사가 붙어야 합니다.
- 동사는 미리 선언된 행위여야 하고, 필수 역할이 모두 있어야 합니다.

## 8.3 조사가 역할을 정한다

영어는 **어순**으로 역할을 구분합니다. "Yubin rolled the ball"과 "The ball rolled Yubin"은 낱말이 같아도 뜻이 정반대입니다. 한국어는 **격조사**가 역할을 직접 표시하므로, 어순이 바뀌어도 뜻이 유지됩니다.

```aha
대상 유빈
대상 공
행위 굴리다: 주체, 대상

유빈이 공을 굴렸다
공을 유빈이 굴렸다
```

두 문장은 같은 사건(주체 유빈, 대상 공)으로 바뀝니다. 프로그래밍 언어로 말하면 한국어의 조사는 **이름 있는 인자**(`굴리다(주체=유빈, 대상=공)`)와 같은 역할을 합니다.

### 조사와 역할

| 조사 | 앞말의 타입 | 역할 |
| --- | --- | --- |
| 이/가, 은/는 | 대상 | 주체 |
| 을/를 | 대상 | 대상 |
| 에게, 한테 | 대상 | 상대 |
| 으로/로 | 대상 | 도구 |
| 에 | 시각 | 시작 |
| | 위치 | 장소 |
| 부터 | 시각 | 시작 |
| | 위치 | 출발 |
| 까지 | 시각 | 종료 |
| | 위치 | 도착 |
| 에서 | 위치 | 장소 |

**뜻이 여럿인 조사는 앞말의 타입이 정합니다.** "던짐에"의 '에'는 던짐이 시각이므로 "언제"(시작)이고, "입구에"의 '에'는 입구가 위치이므로 "어디서"(장소)입니다. 사람이 문맥으로 하는 구분을, AHAA는 5장의 타입으로 합니다. 이런 방식을 **타입 주도 중의성 해소**라고 부를 수 있습니다.

```aha
기준 시계: 시간축
기준 복도: 위치축
대상 공
정의 출발시각: 시각 = 시계 @ 1 초
정의 도착시각: 시각 = 시계 @ 3 초
정의 입구: 위치 = 복도 @ 0 미터
정의 끝: 위치 = 복도 @ 5 미터
행위 구르다: 주체

공이 출발시각부터 도착시각까지 입구부터 끝까지 굴렀다
공이 출발시각에 입구에서 굴렀다
```

첫 문장의 역할은 주체(공), 시작(출발시각), 종료(도착시각), 출발(입구), 도착(끝)이고, 둘째 문장은 주체, 시작, 장소입니다.

**은/는에 대하여.** 한국어 문법에서 은/는은 격조사가 아니라 화제를 나타내는 보조사입니다("유빈은 공을 굴렸다"는 "유빈에 대해 말하자면"이라는 뉘앙스). AHAA는 명세에서 이 차이가 판정에 영향을 주지 않으므로 은/는을 주체로 단순화해 다룹니다.

### 조사의 형태: 받침 규칙

한국어 조사의 상당수는 앞말에 받침이 있는지에 따라 모양이 바뀝니다. 같은 뜻의 다른 모양을 **이형태**(allomorph)라고 합니다.

| 받침 있음 | 받침 없음 | 예 |
| --- | --- | --- |
| 이 | 가 | 유빈이, 나무가 |
| 은 | 는 | 유빈은, 나무는 |
| 을 | 를 | 공을, 나무를 |
| 으로 | 로 | 책상으로, 나무로 |

'으로/로'에는 예외가 하나 있습니다. **ㄹ 받침** 뒤에는 '로'를 씁니다(연필로, 칼로). AHAA는 이 규칙을 검사합니다.

```aha 오류=K502
대상 유빈
행위 웃다: 주체
유빈가 웃었다
```

```text
예제.aha(3,1): error K502: '유빈' 뒤에는 '가' 대신 '이'를 씁니다: '유빈이'.
```

```aha 오류=K502
대상 유빈
대상 연필
행위 쓰다: 주체
유빈이 연필으로 썼다
```

```text
예제.aha(4,5): error K502: '연필' 뒤에는 '으로' 대신 '로'를 씁니다: '연필로'.
```

### 이론: 컴퓨터는 받침을 어떻게 아는가

유니코드는 현대 한글 음절 11,172자를 U+AC00('가')부터 **규칙적인 순서**로 배열해 두었습니다. 초성 19개, 중성 21개, 종성 28개(받침 없음 포함)의 모든 조합을 차례로 늘어놓은 것이어서, 음절의 번호로부터 초성·중성·종성을 계산할 수 있습니다.

```text
번호 = 음절의 코드 − 0xAC00
초성 = 번호 ÷ 588          (588 = 21 × 28)
중성 = (번호 mod 588) ÷ 28
종성 = 번호 mod 28          (0이면 받침 없음)
```

'빈'(U+BE48)을 계산해 보겠습니다.

```text
번호 = 0xBE48 − 0xAC00 = 4680
초성 = 4680 ÷ 588 = 7      → ㅂ (ㄱ ㄲ ㄴ ㄷ ㄸ ㄹ ㅁ ㅂ 의 여덟째, 0부터 세어 7)
중성 = (4680 mod 588) ÷ 28 = 564 ÷ 28 = 20  → ㅣ
종성 = 4680 mod 28 = 4     → ㄴ
```

종성이 0이 아니므로 받침이 있고, '이'를 써야 합니다. '무'(U+BB34)는 종성이 0이어서 받침이 없고, '필'(U+D544)은 종성이 8(ㄹ)입니다. 사전이나 형태소 분석기 없이 나머지 연산만으로 받침 규칙을 정확히 적용할 수 있는 것은 이 배열 덕분입니다.

## 8.4 행위와 필수 역할

### 행위 선언

```text
행위 기본형: 필수역할, 필수역할, ...
행위 기본형 (활용형, ...): 필수역할, ...
```

```aha
행위 웃다: 주체
행위 설계하다: 주체, 대상
행위 출발하다: 주체, 시작
```

기본형은 '-다'로 끝나야 합니다. `:` 뒤에는 그 행위에 **반드시 있어야 하는 역할**을 적습니다. **주체는 적지 않아도 항상 필수**입니다.

### 이론: 논항 구조

언어학에서는 동사마다 함께 와야 하는 성분의 수와 종류가 정해져 있다고 봅니다. '웃다'는 누가(주어) 하나면 완전한 문장이 되지만, '설계하다'는 누가와 무엇을이 모두 있어야 합니다. "유빈이 설계했다"는 무엇을 설계했는지가 빠져 불완전하게 느껴집니다. 동사가 요구하는 이런 성분을 **논항**(argument)이라 하고, 동사마다 논항의 틀을 **논항 구조**라고 합니다. 화학에서 원자가 결합할 수 있는 손의 수를 원자가(valence)라 하듯, 프랑스 언어학자 Lucien Tesnière(1959, *Éléments de syntaxe structurale*)는 동사가 거느리는 성분의 수를 **결합가**(valency)라고 불렀습니다.

AHAA의 `행위` 선언은 이 논항 구조를 명시하는 것입니다.

### 주어 생략 금지

한국어는 문맥으로 알 수 있는 주어를 자주 생략합니다("어제 뭐 했어?" "영화 봤어."). 이런 언어를 **주어 생략 언어**(pro-drop language)라고 합니다. 대화에서는 자연스럽지만, 명세에서 "누가"가 빠지면 책임과 관계가 모호해집니다. 그래서 AHAA는 모든 행위에 주체를 요구합니다.

```aha 오류=K504
대상 유빈
대상 설계안
행위 설계하다: 주체, 대상

이렇게 설계를 하다
```

```text
예제.aha(5,9): error K504: 행위 '설계하다'에는 '주체' 역할이 필요합니다. 누가 했는지(주체)가 없습니다. '유빈이'처럼 이/가 조사로 밝히세요.
```

```aha 오류=K504
대상 유빈
대상 공
행위 굴리다: 주체, 대상
유빈이 굴렸다
```

```text
예제.aha(4,5): error K504: 행위 '굴리다'에는 '대상' 역할이 필요합니다. 무엇을 했는지(대상)가 없습니다. '설계안을'처럼 을/를 조사로 밝히세요.
```

### 문장에서 쓸 수 있는 역할

| 역할 | 채우는 방법 |
| --- | --- |
| 주체 | 이/가, 은/는 + 대상 |
| 대상 | 을/를 + 대상 |
| 상대 | 에게, 한테 + 대상 |
| 도구 | 으로/로 + 대상 |
| 시작 | 에, 부터 + 시각 |
| 종료 | 까지 + 시각 |
| 장소 | 에, 에서 + 위치 |
| 출발 | 부터 + 위치 |
| 도착 | 까지 + 위치 |
| 방식 | 이렇게·그렇게·저렇게 (9장) |

## 8.5 동사의 활용을 알아보기

문장에는 기본형 '굴리다'가 아니라 '굴렸다', '굴린다'처럼 **활용형**이 옵니다. 컴파일러는 활용형을 기본형과 연결해야 합니다. 형태소 분석기 같은 큰 도구 없이, 한국어 문법에 정리된 규칙만으로 이 일을 합니다.

### 규칙 1: 어간은 그대로, 마지막 음절은 초성이 같다

기본형에서 '다'를 뗀 부분이 **어간**입니다('굴리다' → '굴리'). 활용형은 다음을 만족해야 합니다.

1. 어간의 마지막 음절을 뺀 앞부분('굴')이 그대로 있습니다.
2. 그다음 음절은 어간 마지막 음절('리')과 **초성이 같습니다**('렸'의 초성 ㄹ).
3. 낱말이 '다'로 끝납니다.

### 규칙 2: 중성은 같거나, 모음 축약으로 바뀐다

어간 마지막 음절에 받침이 없으면, 뒤에 붙는 '-았/었/였-'과 합쳐지며 모음이 바뀌기도 합니다. 이를 **모음 축약**이라고 합니다. AHAA가 인정하는 축약은 다음과 같습니다.

| 어간 모음 | 바뀐 모음 | 예 |
| --- | --- | --- |
| ㅏ | ㅐ | 하다 → 했다 |
| ㅣ | ㅕ | 지다 → 졌다, 굴리다 → 굴렸다 |
| ㅗ | ㅘ | 오다 → 왔다 |
| ㅜ | ㅝ | 주다 → 줬다 |
| ㅚ | ㅙ | 되다 → 됐다 |
| ㅡ | ㅓ | 쓰다 → 썼다 |
| ㅡ | ㅏ | 바쁘다 → 바빴다 |

어간 마지막 음절에 받침이 있으면('먹다'의 '먹') 그 음절은 그대로 있어야 합니다(먹었다, 먹는다).

### 규칙 3: 르 불규칙

'구르다 → 굴렀다', '부르다 → 불렀다'처럼 어간이 '르'로 끝나는 동사는 'ㅡ'가 빠지면서 앞 음절에 ㄹ 받침이 붙고, 그다음 음절은 ㄹ로 시작합니다. 학교 문법에서 **르 불규칙**이라고 부르는 규칙적인 변화여서 컴파일러가 알아봅니다.

### 규칙 4: 기능동사 구문

'설계하다'는 '설계를 하다'로도 씁니다. 명사에 '하다'가 붙은 동사를 이렇게 나눠 쓰는 것을 **기능동사**(경동사) 구문이라고 합니다. 문장 끝이 '하다'의 활용형이고 바로 앞 낱말이 "명사 + 을/를"이며, 둘을 붙인 것이 선언된 행위의 활용형이면 같은 행위로 봅니다. 이때 앞 낱말은 대상이 아니라 행위의 일부입니다.

```aha
대상 유빈
대상 설계안
행위 설계하다: 주체, 대상
유빈이 설계안을 설계를 했다
```

### 그 밖의 불규칙: 직접 적기

'듣다 → 들었다'(ㄷ 불규칙), '돕다 → 도왔다'(ㅂ 불규칙) 같은 다른 불규칙 활용은 위 규칙으로 알아볼 수 없습니다. 이때는 선언에 활용형을 괄호로 적습니다. 컴파일러가 확실하지 않은 것을 짐작하지 않게 하려는 선택입니다.

```aha
대상 유빈
행위 듣다 (들었다, 듣는다): 주체
유빈이 들었다
```

규칙으로 알아볼 수 없고 괄호에도 없는 활용형은 `K503`입니다. 예를 들어 '마셨다'는 '먹다'의 활용형이 아닙니다.

```aha 오류=K503
대상 유빈
대상 물
행위 먹다: 주체, 대상
유빈이 물을 마셨다
```

```text
예제.aha(4,8): error K503: '마셨다'에 해당하는 행위가 선언되지 않았습니다. '행위 ...다: 주체, ...'로 먼저 선언하세요.
```

한 활용형이 두 행위와 모두 맞으면 어느 쪽인지 정할 수 없으므로 `K507`입니다.

```aha 오류=K507
대상 유빈
행위 뛰다: 주체
행위 달리다 (뛰었다): 주체
유빈이 뛰었다
```

## 8.6 낱말의 오류

| 상황 | 예 | 진단 |
| --- | --- | --- |
| 선언되지 않은 이름 | `철수가 공을 굴렸다` | `K501` |
| 조사가 없음 | `유빈 공을 굴렸다` | `K501` |
| 조사 형태가 받침과 맞지 않음 | `유빈가` | `K502` |
| 같은 역할이 두 번 | `유빈이 유빈이 공을 굴렸다` | `K505` |
| 조사와 타입이 맞지 않음 | `공에` (공은 대상) | `K506` |
| 문장에 쓸 수 없는 기호 | `유빈이 공을 = 굴렸다` | `K500` |

```aha 오류=K501
대상 공
행위 굴리다: 주체, 대상
철수가 공을 굴렸다
```

```text
예제.aha(3,1): error K501: '철수가'를 알 수 없습니다. 문장의 낱말은 '대상'·'정의'로 선언한 이름에 조사를 붙인 것이어야 합니다.
```

```aha 오류=K506
기준 시계: 시간축
대상 유빈
대상 공
정의 던짐: 시각 = 시계 @ 1 초
행위 굴리다: 주체, 대상
유빈이 던짐을 굴렸다
```

```text
예제.aha(6,5): error K506: '던짐을': '을' 앞에는 '대상'이 와야 하지만 '던짐'은 시각(시계)입니다.
```

**문장과 선언 줄의 구분.** 키워드로 시작하지 않는 줄은 모두 문장으로 읽습니다. 그래서 `정의`를 빠뜨린 줄은 "행위로 끝나지 않는 문장"으로 보고됩니다.

```aha 오류=K500
시작 = 1
```

```text
예제.aha(1,6): error K500: 문장은 행위(동사)로 끝나야 합니다. 값을 선언하려면 '정의'로 시작하세요.
```

## 8.7 시간 순서

문장의 시작과 종료도 6장의 사건처럼 순서를 지켜야 합니다. 종료가 시작보다 앞서면 `K402`입니다. 위치(출발, 도착)는 뒤로 움직일 수 있으므로 순서를 검사하지 않습니다.

```aha 오류=K402
기준 시계: 시간축
대상 공
정의 가: 시각 = 시계 @ 1 초
정의 나: 시각 = 시계 @ 3 초
행위 구르다: 주체
공이 나부터 가까지 굴렀다
```

## 정리

- 키워드 없는 줄은 문장이며, 마지막 낱말이 행위, 나머지는 "이름 + 조사"입니다.
- 조사가 역할을 정하고, '에'·'부터'·'까지'처럼 뜻이 여럿인 조사는 앞말의 타입이 뜻을 정합니다.
- 조사의 형태는 받침 규칙을 따르며, 컴파일러는 유니코드 번호 계산으로 받침을 압니다.
- `행위 기본형: 역할`로 논항 구조를 선언하고, 주체는 항상 필수입니다.
- 활용형은 모음 축약, 르 불규칙, 기능동사 구문으로 기본형과 연결하며, 그 밖의 불규칙은 직접 적습니다.

## 연습 문제

1. '책'(U+CC45)의 초성·중성·종성 번호를 계산하고, 알맞은 목적격 조사를 고르세요.
2. 다음 문장들이 각각 어떤 진단을 내는지 예상해 보세요(대상 유빈·공, 행위 굴리다: 주체, 대상).
   (가) `공이 유빈을 굴렸다` (나) `유빈은 공를 굴렸다` (다) `유빈이 공을 굴린다`
3. '나누다'를 행위로 선언하고 "유빈이 공을 나눴다"를 쓰면 컴파일될까요? 어떤 규칙 때문인가요?

<details>
<summary>풀이</summary>

1. 0xCC45 − 0xAC00 = 8261. 초성 8261 ÷ 588 = 14(ㅊ), 중성 (8261 mod 588) ÷ 28 = 29 ÷ 28 = 1(ㅐ), 종성 8261 mod 28 = 1(ㄱ). 받침이 있으므로 '책을'입니다.
2. (가) 컴파일됩니다. 공이 주체, 유빈이 대상인 사건입니다. 문법은 뜻이 이상한지를 판단하지 않습니다. (나) `K502`, '공'에는 받침이 있으므로 '공을'입니다. (다) 컴파일됩니다. 현재 시제 문장입니다(11장).
3. 컴파일됩니다. '나누'의 마지막 음절 '누'(ㅜ)가 '눴'(ㅝ)로 바뀌는 모음 축약(ㅜ → ㅝ)이고, 앞부분 '나'는 그대로이기 때문입니다.

```aha
대상 유빈
대상 공
대상 책
행위 굴리다: 주체, 대상
행위 나누다: 주체, 대상
공이 유빈을 굴렸다
유빈이 공을 굴린다
유빈이 공을 나눴다
유빈이 책을 나눴다
```
