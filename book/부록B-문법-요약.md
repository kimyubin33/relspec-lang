# 부록 B. 문법 요약

RelSpec 0.5의 문법을 확장 바쿠스-나우르 형식(EBNF)으로 정리합니다. EBNF는 프로그래밍 언어의 문법을 적는 표준적인 표기로, 다음 기호를 씁니다.

| 표기 | 뜻 |
| --- | --- |
| `A = ... ;` | A는 ...이다 |
| `"정의"` | 그대로 쓰는 글자 |
| `A B` | A 다음에 B |
| `A \| B` | A 또는 B |
| `[ A ]` | A는 있어도 되고 없어도 됨 |
| `{ A }` | A를 0번 이상 반복 |
| `( A )` | 묶음 |

## 파일과 줄

```text
파일   = { 줄 } ;
줄     = [ 문장 ] [ 주석 ] 줄끝 ;
주석   = "#" { 줄끝이 아닌 글자 } ;
```

한 줄에는 문장을 하나까지 적습니다. 파일에는 문장이 적어도 하나 있어야 합니다(`K201`).

## 문장의 종류

```text
문장 = 정의 | 검사 | 기준선언 | 대상선언 | 사건선언
     | 미지선언 | 조건 | 목표 | 관측
     | 행위선언 | 참조정의 | 한국어문장 ;

정의     = "정의" 이름 ":" 타입 "=" 식 ;
검사     = "검사" 이름 "=" 식 ;
기준선언 = "기준" 이름 ":" ( "시간축" | "위치축" ) ;
대상선언 = "대상" 이름 ;
사건선언 = "사건" 이름 ":" 역할값 { "," 역할값 } ;
역할값   = 역할이름 "=" 식 ;
미지선언 = "미지" 이름 ":" 타입 "=" ( "?" | 이름 "@" "?" ) ;
조건     = "조건" 이름 "=" 식 ;
목표     = "목표" 이름 "=" 식 ;
관측     = "관측" 이름 "=" 식 ;
행위선언 = "행위" 기본형 [ "(" 활용형 { "," 활용형 } ")" ] [ ":" 역할이름 { "," 역할이름 } ] ;
참조정의 = "참조" 숫자 ":" 본문 ;
```

- `본문`은 `:` 뒤부터 줄 끝까지의 모든 글자이며, `#`도 본문에 포함됩니다.
- `기본형`은 `-다`로 끝나는 이름입니다.
- 미지선언에서 `?`만 쓰는 형식은 정수·시간·거리, `이름 @ ?` 형식은 시각·위치입니다.

## 한국어 문장

```text
한국어문장 = [ 이름 ":" ] { 낱말 } 행위어 [ 인용 ] ;
낱말       = 이름 조사 | 지시대명사 조사 | 지시부사 | 숫자 "%" ;
지시부사   = "이렇게" | "그렇게" | "저렇게" ;
지시대명사 = "이것" | "그것" | "저것" ;
조사       = "이" | "가" | "은" | "는" | "을" | "를"
           | "에게" | "한테" | "으로" | "로"
           | "에" | "에서" | "부터" | "까지" ;
인용       = "(" "참조" 숫자 { "," "참조" 숫자 } ")" ;
```

- 키워드로 시작하지 않는 줄은 모두 한국어 문장입니다.
- `이름 조사`는 띄어쓰기 없이 붙여 씁니다(`유빈이`). 컴파일러는 낱말 끝에서 조사를 떼어 낸 앞부분이 선언된 이름인지 확인합니다.
- `행위어`는 선언된 행위의 기본형이나 활용형입니다. "명사를 하다" 꼴의 기능동사 구문도 됩니다(8장).
- `숫자 "%"`는 문장 하나에 한 번까지입니다.

## 식

우선순위가 낮은 것부터 적습니다. 같은 단계의 연산자는 왼쪽부터 묶습니다.

```text
식       = 논리합 ;
논리합   = 논리곱 { "또는" 논리곱 } ;
논리곱   = 같음 { "그리고" 같음 } ;
같음     = 비교 { ( "==" | "!=" ) 비교 } ;
비교     = 덧셈 { ( "<" | "<=" | ">" | ">=" ) 덧셈 } ;
덧셈     = 곱셈 { ( "+" | "-" ) 곱셈 } ;
곱셈     = 단항 { "*" 단항 } ;
단항     = ( "-" | "아님" ) 단항 | 기본 ;
기본     = 숫자 [ 단위 | "%" ]
         | "참" | "거짓"
         | 이름
         | 이름 "." 역할이름
         | 이름 "@" 단항
         | "(" 식 ")" ;
```

## 어휘

```text
이름     = 이름첫글자 { 이름글자 } ;      (예약어와 같으면 안 됨)
숫자     = 십진숫자 { 십진숫자 } ;
타입     = "정수" | "논리" | "시간" | "거리" | "시각" | "위치" | "대상" | "정도" ;
단위     = "밀리초" | "초" | "밀리미터" | "센티미터" | "미터" ;
역할이름 = 이름 | "대상" ;
```

- `이름첫글자`는 유니코드 일반 범주가 Lu, Ll, Lt, Lm, Lo인 글자 또는 `_`입니다.
- `이름글자`는 여기에 숫자(Nd)와 결합 부호(Mn, Mc)를 더한 것입니다.
- 이름은 NFC로 정규화한 뒤 비교합니다.
- 공백(띄어쓰기, 탭)은 토큰 사이를 나누는 것 외에는 뜻이 없습니다. 그래서 `1초`와 `1 초`는 같습니다.

## 역할

| 쓰는 곳 | 역할 |
| --- | --- |
| `사건` 선언 | 주체, 대상, 관측자, 시작, 종료, 출발, 도착 |
| 문장과 `행위` 선언 | 주체, 대상, 상대, 도구, 시작, 종료, 장소, 출발, 도착, 방식 |
| `사건.역할`로 읽을 때 추가 | 소요, 이동 |
