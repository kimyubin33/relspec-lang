# 부록 B. 문법 요약

AHAA 0.14의 문법을 확장 바쿠스-나우르 형식(EBNF)으로 정리합니다. EBNF는 프로그래밍 언어의 문법을 적는 표준적인 표기로, 다음 기호를 씁니다.

| 표기 | 뜻 |
| --- | --- |
| `A = ... ;` | A는 ...이다 |
| `"정의"` | 그대로 쓰는 글자 |
| `A B` | A 다음에 B |
| `A \| B` | A 또는 B |
| `[ A ]` | A는 있어도 되고 없어도 됨 |
| `{ A }` | A를 0번 이상 반복 |
| `( A )` | 묶음 |

## 파일과 줄

```text
파일   = { 줄 } ;
줄     = [ 문장 ] [ 주석 ] 줄끝 ;
주석   = "#" { 줄끝이 아닌 글자 } ;
```

한 줄에는 문장을 하나까지 적습니다. 파일에는 문장이 적어도 하나 있어야 합니다(`K201`).

## 문장의 종류

```text
문장 = 정의 | 검사 | 기준선언 | 대상선언 | 단위선언 | 사건선언
     | 미지선언 | 조건 | 목표 | 관측
     | 행위선언 | 규칙선언 | 참조정의 | 본문줄 | 딸린줄
     | 주제 | 낱말정의 | 장면 | 한국어문장 ;

정의     = "정의" 이름 [ ":" 타입 ] "=" 식 ;
검사     = "검사" [ 이름 "=" ] 식 ;
기준선언 = "기준" 이름 ":" ( "시간축" | "위치축" ) ;
대상선언 = "대상" 이름 { "," 이름 } ;
단위선언 = "단위" 이름 { "," 이름 } ;
사건선언 = "사건" 이름 ":" 역할값 { "," 역할값 } ;
역할값   = 역할이름 "=" 식 ;
미지선언 = "미지" 이름 { "," 이름 } ":" 타입 [ "=" ( "?" | 이름 "@" "?" ) ] ;
조건     = "조건" [ 이름 "=" ] 식 ;
목표     = "목표" [ 이름 "=" ] 식 ;
관측     = "관측" 이름 "=" 식 ;
행위선언 = "행위" 행위머리 { "," 행위머리 } [ ":" 역할이름 { "," 역할이름 } ] ;
행위머리 = 기본형 [ "(" 활용형 { "," 활용형 } ")" ] ;
규칙선언 = "규칙" 이름 ":" 식 "이면" 식 [ "최소로" | "곱으로" ] ;
참조정의 = "참조" 숫자 ":" 본문 ;
본문줄   = "본문" ":" 본문 ;
딸린줄   = "-" 본문 ;

주제     = "주제" ( "<" 글 ">" | 글 ) ;
낱말정의 = "낱말" 이름 ":" 차원 { "," 차원 } ;
차원     = 이름 [ "*" ] [ "(" 타입 ")" ] [ 숫자 ] ;      (숫자는 가중치 1~100)
장면     = "장면" 이름 줄끝 장면줄 { 장면줄 } ;
장면줄   = 들여쓰기 이름 [ 이름 ] [ ":" 채움 { "," 채움 } ] ;
채움     = 이름 ( 식 | 글 ) ;
```

- 장면줄은 `장면` 줄보다 들여 쓴 줄입니다. 바로 위의 장면줄보다 더 들여 쓰면 그 낱말의 안에 있습니다.
- 장면줄의 첫 이름은 낱말이고, 둘째 이름은 그 낱말로 만든 것에 붙이는 이름입니다. 생략하면 낱말의 이름을 씁니다.
- 채움의 값은 그 차원에 타입이 있으면 식, 없으면 쉼표 앞까지의 글입니다(19장).

- 딸린줄은 가장 가까운 위의 한국어문장, 참조정의, 본문줄에 딸립니다. 사이에 다른 문장이 있으면 `K200`입니다(16.9).

- 검사·조건·목표에서 `이름 "="`는 이름 바로 뒤의 토큰이 `=`일 때만 이름으로 읽습니다. 아니면 식의 시작입니다(16장).
- 정의에서 타입을 생략하면 식의 타입을 따릅니다.
- 미지선언에서 `=` 뒤를 생략할 수 있는 것은 정수·시간·거리·선언한 단위입니다. 시각·위치는 `= 이름 @ ?`가 필요합니다.

- `본문`은 `:` 뒤부터 줄 끝까지의 모든 글자이며, `#`도 본문에 포함됩니다.
- `기본형`은 `-다`로 끝나는 이름입니다.
- 규칙선언의 `이면`, `최소로`, `곱으로`는 이 자리에서만 특별한 뜻을 가지며 예약어가 아닙니다. 첫 식이 전제, 둘째 식이 강도입니다.
- 미지선언에서 `?`만 쓰는 형식은 정수·시간·거리, `이름 @ ?` 형식은 시각·위치입니다.

## 한국어 문장

```text
한국어문장 = [ 이름 ":" ] ( 사실문 | 조건문 ) [ 인용 ] [ ":" 본문 ] ;
사실문     = { 낱말 } 행위어 ;
조건문     = { 낱말 } 조건행위어 { 낱말 | 방식 } 행위어 [ 방식 ] ;
방식       = "최소로" | "곱으로" ;
낱말       = 이름 조사 | 지시대명사 조사 | 지시부사 | 숫자 "%" ;
지시부사   = "이렇게" | "그렇게" | "저렇게" ;
지시대명사 = "이것" | "그것" | "저것" ;
조사       = "이" | "가" | "은" | "는" | "을" | "를"
           | "에게" | "한테" | "으로" | "로"
           | "에" | "에서" | "부터" | "까지" ;
인용       = "(" "참조" 숫자 { "," "참조" 숫자 } ")" ;
```

- 키워드로 시작하지 않는 줄은 모두 한국어 문장입니다.
- 문장 끝의 `":" 본문`은 그 문장의 설명입니다(16장). 줄의 둘째 토큰인 `:`는 이름 뒤의 것이고, 그 뒤에 나오는 `:`가 설명의 시작입니다.
- `이름 조사`는 띄어쓰기 없이 붙여 씁니다(`유빈이`). 컴파일러는 낱말 끝에서 조사를 떼어 낸 앞부분이 선언된 이름인지 확인합니다.
- `행위어`는 선언된 행위의 기본형이나 활용형입니다. "명사를 하다" 꼴의 기능동사 구문도 됩니다(8장).
- `조건행위어`는 선언된 행위의 어간에 `-면`(받침이 없거나 ㄹ 받침) 또는 `-으면`(그 밖의 받침)을 붙인 꼴입니다. 조건문에서 `조건행위어` 앞이 전제, 뒤가 결론입니다. 전제에는 `숫자 "%"`를 쓸 수 없고, 방식은 조건문 하나에 한 번까지입니다(14장).
- `숫자 "%"`는 문장 하나에 한 번까지입니다.

## 식

우선순위가 낮은 것부터 적습니다. 같은 단계의 연산자는 왼쪽부터 묶습니다.

```text
식       = 논리합 ;
논리합   = 논리곱 { "또는" 논리곱 } ;
논리곱   = 같음 { "그리고" 같음 } ;
같음     = 비교 { ( "==" | "!=" ) 비교 } ;
비교     = 덧셈 { ( "<" | "<=" | ">" | ">=" ) 덧셈 } ;
덧셈     = 곱셈 { ( "+" | "-" ) 곱셈 } ;
곱셈     = 단항 { "*" 단항 } ;
단항     = ( "-" | "아님" ) 단항 | 기본 ;
기본     = 수 [ 단위 | "%" ]
         | "참" | "거짓"
         | 이름
         | 이름 "." 역할이름
         | 이름 "@" 단항
         | "(" 식 ")" ;
```

## 어휘

```text
이름     = 이름첫글자 { 이름글자 } ;      (예약어와 같으면 안 됨)
숫자     = 십진숫자 { 십진숫자 } ;
수       = 숫자 { 큰수낱말 [ 숫자 ] } ;                 (예: 120만, 1억 2000만)
큰수낱말 = "십" | "백" | "천" | "만" | "십만" | "백만" | "천만"
         | "억" | "십억" | "백억" | "천억" | "조" | "십조" | "백조" | "천조" ;
타입     = "정수" | "논리" | "시간" | "거리" | "시각" | "위치" | "대상" | "정도"
         | 선언한단위 ;
단위     = "밀리초" | "초" | "분" | "시간" | "일"
         | "밀리미터" | "센티미터" | "미터" | "킬로미터"
         | 선언한단위 ;
역할이름 = 이름 | "대상" ;
```

- `이름첫글자`는 유니코드 일반 범주가 Lu, Ll, Lt, Lm, Lo인 글자 또는 `_`입니다.
- `이름글자`는 여기에 숫자(Nd)와 결합 부호(Mn, Mc)를 더한 것입니다.
- 이름은 NFC로 정규화한 뒤 비교합니다.
- `선언한단위`는 `단위`로 선언한 이름입니다. `분`, `일`, `킬로미터`와 큰수낱말은 수 바로 뒤에서만 그 뜻으로 읽으며 예약어가 아닙니다. 큰수낱말과 단위는 붙여 쓸 수 있습니다(`3만원`).
- 공백(띄어쓰기, 탭)은 토큰 사이를 나누는 것 외에는 뜻이 없습니다. 그래서 `1초`와 `1 초`는 같습니다.

## 역할

| 쓰는 곳 | 역할 |
| --- | --- |
| `사건` 선언 | 주체, 대상, 관측자, 시작, 종료, 출발, 도착 |
| 문장과 `행위` 선언 | 주체, 대상, 상대, 도구, 시작, 종료, 장소, 출발, 도착, 방식 |
| `사건.역할`로 읽을 때 추가 | 소요, 이동 |
