# 10장. 정도와 퍼지 논리

> 이 장에서 배우는 것
> - 참과 거짓 사이의 값, 정도(%)
> - Zadeh의 퍼지 논리와 그 연산
> - "떨어지되 떨어지지 않는다": 모순율과 배중률이 깨지는 원리
> - 정도와 확률의 차이
> - 고전 논리가 퍼지 논리의 특수한 경우인 이유

이 장의 기능은 RelSpec 0.4에서 들어왔습니다.

## 10.1 참과 거짓 사이

"방이 어둡다"는 참일까요, 거짓일까요? 해 질 무렵의 방은 완전히 어둡지도, 완전히 밝지도 않습니다. "이 커피는 뜨겁다", "이 사람은 키가 크다"도 마찬가지입니다. 일상의 많은 개념은 경계가 흐릿하고, 참과 거짓 사이의 **정도**로 말하는 것이 자연스럽습니다.

RelSpec에서는 문장에 정도를 붙일 수 있습니다.

```kpl
대상 컵
행위 떨어지다: 주체

떨어짐: 컵이 70% 떨어졌다
```

"컵이 70%만큼 떨어졌다"는 것이 사실이라는 뜻입니다. 이 문장에서 떨어진 정도는 70%이고, 떨어지지 않은 정도는 30%입니다.

## 10.2 이론: 퍼지 집합과 퍼지 논리

1965년 Lotfi Zadeh는 논문 "Fuzzy Sets"(*Information and Control* 8권)에서 **퍼지 집합**을 제안했습니다. 고전적인 집합에서는 원소가 집합에 "속하거나 속하지 않거나" 둘 중 하나입니다. 퍼지 집합에서는 원소가 집합에 속하는 **정도**가 0과 1 사이의 수입니다. 예를 들어 "키 큰 사람"의 집합에 키 175cm인 사람이 0.6만큼 속할 수 있습니다.

명제의 참도 같은 방식으로 다룰 수 있습니다. 이것이 **퍼지 논리**입니다. RelSpec은 정도를 0%~100%의 정수로 나타내고, Zadeh가 제안한 표준 연산을 씁니다.

| 연산 | 정의 | 예 (A = 70%, B = 40%) |
| --- | --- | --- |
| A 그리고 B | min(A, B) | 40% |
| A 또는 B | max(A, B) | 70% |
| 아님 A | 100% − A | 30% |

직관은 이렇습니다. "A이면서 B"는 둘 중 약한 쪽만큼만 참이고(사슬은 가장 약한 고리만큼 강하다), "A이거나 B"는 둘 중 강한 쪽만큼 참이며, "A가 아님"은 A가 참이지 않은 만큼 참입니다.

## 10.3 정도 타입

### 리터럴과 정의

정도는 `숫자%`로 씁니다. 0에서 100 사이의 정수이며, 범위를 벗어나면 `K520`입니다.

```kpl
정의 밝기: 정도 = 30%
정의 온기: 정도 = 85%
검사 비교 = 온기 > 밝기
```

```kpl 오류=K520
정의 가: 정도 = 150%
```

```text
예제.kpl(1,12): error K520: 정도는 0%에서 100% 사이입니다.
```

### 문장의 정도

문장 안 어디에든 `숫자%`를 한 번 적으면 그 문장의 정도가 됩니다. 적지 않으면 100%, 즉 고전적인 사실입니다. 정도를 식에서 쓰려면 문장 앞에 `이름:`을 붙입니다. 이름은 그 문장의 정도를 값으로 가집니다.

```kpl
대상 컵
행위 떨어지다: 주체

떨어짐: 컵이 70% 떨어졌다
확실함: 컵이 떨어졌다
검사 정도들 = 떨어짐 == 70% 그리고 확실함 == 100%
```

### 연산의 규칙

| 연산 | 정도에서 |
| --- | --- |
| `그리고`, `또는`, `아님` | 퍼지 연산 (10.2의 표) |
| `<`, `<=`, `>`, `>=`, `==`, `!=` | 정도끼리 비교, 결과는 논리 |
| `+`, `-`, `*` | 쓸 수 없음 (`K304`) |

정도를 더하는 것은 퍼지 논리의 연산이 아니므로 허용하지 않습니다. 70%와 40%를 더한 110%는 정도가 아닙니다.

```kpl 오류=K304
정의 가: 정도 = 30% + 20%
```

정도와 정수는 다른 타입입니다. `30%`와 `30`은 같지 않습니다.

```kpl 오류=K304
정의 가: 정도 = 30%
정의 나: 정수 = 30
검사 다 = 가 == 나
```

`검사`의 결과는 논리여야 하므로, 정도를 바로 검사로 쓸 수는 없습니다. 기준과 비교해 논리로 만듭니다.

```kpl 오류=K303
대상 컵
행위 떨어지다: 주체
가: 컵이 떨어졌다
검사 나 = 가
```

```kpl
대상 컵
행위 떨어지다: 주체
가: 컵이 떨어졌다
검사 나 = 가 >= 50%
```

## 10.4 떨어지되 떨어지지 않는다

이제 이 장의 핵심입니다. 고전 논리에는 2천 년 넘게 지켜진 두 법칙이 있습니다.

- **모순율**: "A 그리고 A가 아님"은 언제나 거짓이다. (어떤 것도 동시에 그러면서 그렇지 않을 수 없다.)
- **배중률**: "A 또는 A가 아님"은 언제나 참이다. (그렇거나 그렇지 않거나 둘 중 하나다.)

퍼지 논리에서는 둘 다 성립하지 않습니다.

```kpl
대상 컵
행위 떨어지다: 주체

떨어짐: 컵이 70% 떨어졌다
정의 공존: 정도 = 떨어짐 그리고 아님 떨어짐
정의 둘중하나: 정도 = 떨어짐 또는 아님 떨어짐
검사 모순율이깨짐 = 공존 == 30%
검사 배중률이깨짐 = 둘중하나 == 70%
```

계산해 보면 다음과 같습니다.

```text
떨어짐 그리고 아님 떨어짐 = min(70%, 30%) = 30%     (0%가 아님)
떨어짐 또는 아님 떨어짐   = max(70%, 30%) = 70%     (100%가 아님)
```

"떨어졌으면서 떨어지지 않았다"가 30%만큼 참입니다. 컵이 떨어진 상태와 떨어지지 않은 상태가 **동시에 일부씩 성립**하는 것이 정확한 값으로 표현됩니다. 이것이 RelSpec이 퍼지 논리를 택한 이유입니다.

### 그대로 성립하는 법칙들

퍼지 논리가 고전 논리의 모든 법칙을 버리는 것은 아닙니다. min, max, 100% − x로 정의한 연산에서는 다음이 그대로 성립합니다. 컴파일러로 직접 확인할 수 있습니다.

```kpl
대상 컵
대상 접시
행위 떨어지다: 주체
가: 컵이 70% 떨어졌다
나: 접시가 40% 떨어졌다

검사 드모르간1 = 아님 (가 그리고 나) == (아님 가 또는 아님 나)
검사 드모르간2 = 아님 (가 또는 나) == (아님 가 그리고 아님 나)
검사 이중부정 = 아님 아님 가 == 가
검사 멱등 = (가 그리고 가) == 가 그리고 (가 또는 가) == 가
검사 분배 = (가 그리고 (나 또는 아님 나)) == ((가 그리고 나) 또는 (가 그리고 아님 나))
```

| 법칙 | 고전 논리 | Zadeh 퍼지 논리 |
| --- | --- | --- |
| 교환, 결합 | 성립 | 성립 |
| 분배 | 성립 | 성립 |
| 드모르간 | 성립 | 성립 |
| 이중 부정 | 성립 | 성립 |
| 멱등 (A 그리고 A = A) | 성립 | 성립 |
| 모순율 | 성립 | **깨짐** |
| 배중률 | 성립 | **깨짐** |

수학적으로 말하면, 0~100%에 min, max, 100% − x를 갖춘 구조는 **드모르간 대수**(De Morgan algebra)이지만 **불 대수**(Boolean algebra)는 아닙니다. 불 대수가 되려면 모순율과 배중률이 성립해야 하기 때문입니다.

### 다른 선택지

"그리고"를 min이 아닌 다른 연산으로 정의하는 퍼지 논리도 있습니다. 이런 연산들을 통틀어 **t-노름**(t-norm)이라고 합니다.

| t-노름 | A 그리고 B | 70% 그리고 30%의 값 |
| --- | --- | --- |
| 최솟값 (Zadeh, Gödel) | min(A, B) | 30% |
| 곱 | A × B | 21% |
| Łukasiewicz | max(0, A + B − 100%) | 0% |

흥미롭게도 Łukasiewicz t-노름을 쓰면 "A 그리고 아님 A"가 언제나 0이 되어 모순율이 다시 성립합니다. 어떤 연산을 고르느냐가 "공존"을 허락할지 말지를 정하는 셈입니다. RelSpec은 사용자가 원한 "공존"을 표현할 수 있고, 가장 널리 쓰이며, 정수 계산이 정확한 min을 택했습니다.

## 10.5 고전 논리는 특수한 경우다

참을 100%, 거짓을 0%로 보면, min, max, 100% − x는 고전 논리의 진리표를 그대로 만들어 냅니다.

| A | B | min(A, B) | 고전 논리의 A 그리고 B |
| --- | --- | --- | --- |
| 100% | 100% | 100% | 참 |
| 100% | 0% | 0% | 거짓 |
| 0% | 100% | 0% | 거짓 |
| 0% | 0% | 0% | 거짓 |

그래서 RelSpec에서는 `논리` 값과 `정도` 값을 `그리고`, `또는`으로 섞어 쓸 수 있습니다. 섞으면 참은 100%, 거짓은 0%로 바뀌고 결과는 정도입니다.

```kpl
대상 컵
행위 떨어지다: 주체
가: 컵이 70% 떨어졌다
검사 섞기 = (참 그리고 가) == 70% 그리고 (거짓 또는 가) == 70%
```

정도가 0%나 100%인 문장만 쓰면 지금까지의 고전 논리와 결과가 똑같습니다. 퍼지 논리는 고전 논리를 버리는 것이 아니라 **넓히는** 것입니다.

## 10.6 정도와 확률은 다르다

"컵이 70% 떨어졌다"와 "컵이 떨어졌을 확률이 70%"는 다른 말입니다.

| | 정도 (퍼지) | 확률 |
| --- | --- | --- |
| 뜻 | 70%만큼 떨어진 것이 **사실**이다 | 떨어졌는지 아닌지 **모른다** |
| 상태 | 하나의 상태가 중간값을 가짐 | 두 상태 중 하나인데 어느 쪽인지 모름 |
| 관측하면 | 그대로 70% | 0% 또는 100%로 확정 |
| 예 | 방이 70% 어둡다 | 내일 비가 올 확률 70% |

확률은 **모름**(불확실성)을, 정도는 **흐릿함**(모호성)을 다룹니다. 내일 비가 오는지는 내일이 되면 확정되지만, 해 질 녘 방이 어두운 정도는 아무리 들여다봐도 70%입니다.

RelSpec에서 "아직 모르는 값"은 7장의 미지값과 관측이 담당합니다. 두 개념을 나누어 두었기 때문에, 앞으로 "정도가 60%~80% 사이인데 정확히는 모른다"처럼 둘을 조합하는 것도 가능해집니다.

## 정리

- `정도`는 0%~100%의 참인 정도입니다. 문장에 `70%`처럼 붙이고, `이름:`으로 식에서 읽습니다.
- `그리고` = min, `또는` = max, `아님` = 100% − 값입니다(Zadeh).
- 퍼지 논리에서는 모순율과 배중률이 깨져, "떨어지되 떨어지지 않는" 상태가 정확한 값을 가집니다.
- 드모르간 법칙, 분배 법칙, 이중 부정 등은 그대로 성립합니다.
- 고전 논리는 0%와 100%만 쓰는 특수한 경우입니다.
- 정도는 흐릿함이고, 확률은 모름입니다.

## 연습 문제

1. A = 60%, B = 25%일 때 다음을 계산하세요: A 그리고 B, A 또는 B, 아님 (A 그리고 B), (아님 A) 또는 (아님 B).
2. "A 그리고 아님 A"가 가장 클 때 A는 얼마이고, 그때의 값은 얼마일까요?
3. 곱 t-노름을 쓴다면 "70% 그리고 70%"는 얼마일까요? min과 비교해 어떤 차이가 있나요?

<details>
<summary>풀이</summary>

1. 25%, 60%, 75%, 75%. 셋째와 넷째가 같은 것은 드모르간 법칙 때문입니다.
2. A = 50%일 때 min(50%, 50%) = 50%로 가장 큽니다. "반쯤 그렇고 반쯤 그렇지 않은" 상태가 모순이 가장 큰 상태입니다.
3. 49%입니다. min에서는 A 그리고 A = A(멱등)이지만, 곱에서는 같은 명제를 거듭할수록 값이 작아집니다. 곱 t-노름에서는 멱등 법칙이 성립하지 않습니다.

```kpl
대상 공
대상 상자
행위 구르다: 주체
가: 공이 60% 굴렀다
나: 상자가 25% 굴렀다
검사 풀이 = (가 그리고 나) == 25% 그리고 (가 또는 나) == 60% 그리고 아님 (가 그리고 나) == 75% 그리고 (아님 가 또는 아님 나) == 75%
반: 공이 50% 굴렀다
검사 최대모순 = (반 그리고 아님 반) == 50%
```
