# RelSpec 언어 교재

**관계를 쓰는 언어: 기초부터 이론까지**

이 책은 RelSpec(파일 확장자 `.kpl`)을 처음 접하는 사람이 기초 문법부터 시작해, 언어가 어떤 이론 위에 서 있는지까지 이해하도록 쓴 기술서입니다. 언어의 각 기능을 소개할 때마다 그 기능이 기대고 있는 수학·언어학·논리학의 배경을 함께 설명합니다.

- **기준 버전:** RelSpec 0.11 (`languageVersion: "0.11"`)
- **예제 검증:** 이 책의 모든 `kpl` 예제는 `tests/book.rs`가 실제 컴파일러로 검사합니다. 컴파일되어야 하는 예제가 실패하거나, 오류가 나야 하는 예제가 다른 오류를 내면 `cargo test`가 실패합니다. 그래서 책의 예제는 언제나 현재 컴파일러와 일치합니다.

## 이 책을 읽는 법

1~4장은 차례대로 읽는 것을 권합니다. 5장부터는 관심 있는 장을 골라 읽어도 되지만, 7장(미지값과 제약)은 11장과 13장의 바탕이 되므로 그 전에 읽어 두면 좋습니다. 13장은 10장 다음에, 14장은 8장과 13장 다음에 읽습니다. 15장은 2장만 읽어도 따라 할 수 있습니다. 16장은 4장과 7장, 8장 다음에, 17장은 9장과 16장 다음에 읽습니다.

**긴 꼴과 짧은 꼴.** 1~14장의 예제는 이름과 타입을 모두 적는 긴 꼴로 되어 있습니다(`정의 마감: 시간 = 2 초`, `조건 하한 = 가 >= 0 초`). 0.9부터는 같은 뜻을 짧게 쓸 수 있고(`정의 마감 = 2 초`, `조건 가 >= 0 초`), 16장에서 다룹니다. 긴 꼴은 지금도 그대로 동작하며, 무엇이 생략된 것인지 알려면 긴 꼴을 먼저 아는 것이 좋습니다.

각 장은 다음 순서로 구성됩니다.

1. **문법**: 무엇을 어떻게 쓰는지
2. **이론**: 왜 그렇게 동작하는지, 어떤 학문적 배경이 있는지
3. **오류**: 어떤 실수를 어떤 진단 코드로 잡는지
4. **연습 문제**: 장 끝에 있으며, 풀이는 바로 아래 접힌 부분에 있습니다

## 표기 규칙

- `kpl` 블록은 RelSpec 소스입니다. 블록 위에 "(앞 예제에 이어서)"라고 적힌 것은 앞 예제 뒤에 붙여 쓴 것입니다.
- `text` 블록은 컴파일러의 출력이나 설명용 표기입니다.
- 오류가 나는 예제에는 블록 바로 아래에 실제 진단 메시지를 적었습니다. 17장의 알림(경고)도 같습니다. 메시지 앞의 `예제.kpl`은 예제를 저장한 파일 이름입니다.
- **굵은 글씨**는 처음 나오는 용어입니다. 용어는 [부록 D](부록D-용어와-참고문헌.md)에 모아 두었습니다.

## 이 책의 범위

RelSpec은 개발 중인 언어입니다. 이 책은 버전마다 함께 갱신되며, 각 장은 그 장의 기능이 들어간 버전을 밝힙니다. 아직 구현되지 않은 계획은 "앞으로"라고 분명히 표시하고, 현재 동작과 섞지 않습니다.
