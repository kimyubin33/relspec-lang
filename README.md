# RelSpec

RelSpec(*Relation Specification*)은 시간, 공간, 사건의 관계를 명세하고 그 조건을 수학적으로 검사하는 언어입니다. 한글 문법부터 개발하며, 영어 문법도 같은 타입과 검사 규칙을 사용하도록 설계합니다.

현재는 Rust로 구현한 0.3 컴파일러입니다. 명령 실행 파일 이름은 `kpl`, 소스 확장자는 `.kpl`입니다. 지원 범위와 다음 단계는 [개발 방향과 구현 상태](DEVELOPMENT.md)에 정리했습니다.

## 실행

Rust와 Cargo가 설치된 환경에서 저장소 폴더를 열고 실행합니다.

```powershell
cargo run --locked -- 검사 "./examples/첫파일.kpl"
cargo run --locked -- 컴파일 "./examples/첫파일.kpl"
cargo run --locked -- 검사 "./examples/사건관계.kpl"
cargo run --locked -- 검사 "./examples/반응마감.kpl"
cargo test --locked
```

`검사`는 정의와 검사 조건의 개수를 요약합니다. `컴파일`은 검사에 통과한 프로그램의 값, 타입, 단위, 식의 연결을 JSON으로 출력합니다. 언어 오류의 종료 코드는 1이며, 파일이나 명령 사용 오류는 2입니다.

Windows용 실행 파일은 `cargo build --release --locked`로 빌드한 뒤 아래와 같이 실행할 수 있습니다.

```powershell
.\target\release\kpl.exe 검사 ".\examples\첫파일.kpl"
```

## 현재 문법

### 값과 검사

```text
정의 시작: 시간 = 1 초
정의 종료: 시간 = 시작 + 250 밀리초
검사 시간순서 = 종료 >= 시작
검사 소요제한 = 종료 - 시작 <= 300 밀리초
```

- `정의`는 타입이 있는 고정값을 선언합니다. 선언한 줄 뒤에서 이름으로 참조할 수 있습니다.
- `검사`는 참이어야 하는 논리식을 선언합니다. 거짓이면 컴파일을 중단하고 검사 이름과 위치를 표시합니다.
- 타입은 `정수`, `논리`, `시간`, `거리`, `시각`, `위치`, `대상`입니다. 시간·시각은 밀리초, 거리·위치는 밀리미터로 정확히 환산합니다.
- 연산은 괄호, 단항 `-`와 `아님`, `*`, `+`와 `-`, 크기 비교, `==`와 `!=`, `그리고`, `또는` 순으로 우선합니다. 곱셈은 적어도 한쪽이 정수여야 합니다.
- UTF-8 파일에 한 줄당 문장 하나를 적습니다. 빈 줄과 `#` 주석을 허용하며, 한 줄은 토큰 128개까지 지원합니다.

### 기준, 시각과 위치

`시간`과 `거리`는 **양**(지속 시간, 길이)이고, `시각`과 `위치`는 **기준 위의 점**입니다. 점은 `기준 @ 값`으로 만듭니다.

```text
기준 실험시계: 시간축
기준 복도: 위치축
정의 던짐: 시각 = 실험시계 @ 1 초
정의 도착점: 위치 = 복도 @ 3 미터
```

| 계산 | 결과 |
| --- | --- |
| 시각 ± 시간, 시간 + 시각 | 같은 기준의 시각 |
| 시각 − 시각 (같은 기준) | 시간 |
| 위치 ± 거리, 거리 + 위치 | 같은 기준의 위치 |
| 위치 − 위치 (같은 기준) | 거리 |
| 시각 + 시각, 위치 + 위치 | 오류 `K305` |
| 서로 다른 기준의 점끼리 계산·비교 | 오류 `K306` |
| 시각 자리에 시간을 쓰거나 시각과 시간을 비교 | 오류 `K307` |

### 대상과 사건

```text
대상 공
대상 유빈
사건 굴림: 주체 = 유빈, 대상 = 공, 시작 = 던짐, 종료 = 던짐 + 1500 밀리초, 출발 = 복도 @ 0 미터, 도착 = 도착점
사건 잡기: 주체 = 유빈, 시작 = 굴림.종료 + 200 밀리초
검사 순서 = 잡기.시작 > 굴림.종료
검사 소요제한 = 굴림.소요 <= 2 초
```

- 역할: `주체`·`대상`·`관측자`(대상), `시작`·`종료`(시각), `출발`·`도착`(위치).
- `시작`은 필수입니다. `종료`를 생략하면 시작과 같은 시각의 순간 사건이 됩니다. `출발`과 `도착`은 함께 적습니다.
- 같은 사건의 시작·종료, 출발·도착은 같은 기준에 있어야 하며, 종료가 시작보다 앞서면 `K402`입니다.
- `사건.역할`로 역할 값을 읽고, `사건.소요`(종료 − 시작)와 `사건.이동`(도착 − 출발)으로 차이를 읽습니다.
- 대상끼리는 `==`, `!=`로 같은지만 비교합니다.

### 미지값, 조건, 목표, 관측

값을 아직 모르는 양은 `미지`로 선언하고, `조건`으로 범위를 좁힌 뒤 `목표`가 **보장**·**가능**·**불가능** 중 무엇인지 판정합니다.

```text
기준 실험시계: 시간축
사건 자극: 시작 = 실험시계 @ 1000 밀리초
미지 반응: 시각 = 실험시계 @ ?
조건 반응은자극뒤 = 반응 >= 자극.시작
조건 지연상한 = 반응 - 자극.시작 <= 200 밀리초
목표 마감준수 = 반응 <= 실험시계 @ 1100 밀리초
```

```text
검사 통과 | 정의 0개, 검사 0개, 기준 1개, 사건 1개, 미지 1개, 조건·관측 2개, 목표 1개
미지 '반응': 1000 밀리초 ~ 1200 밀리초 (실험시계 기준)
목표 '마감준수': 가능 (보장 여부를 확정하려면 관측 필요: 반응)
```

- `미지 이름: 시간 = ?`(정수·시간·거리), `미지 이름: 시각 = 기준 @ ?`(시각·위치)로 선언합니다.
- `조건`은 모든 해가 따라야 하는 가정입니다. 조건끼리 모순이면 뒤에 나온 조건에서 `K404`를 냅니다.
- `목표`는 컴파일을 멈추지 않고 판정만 기록합니다. **보장**은 모든 해에서, **가능**은 일부 해에서 성립하며, **불가능**은 어떤 해에서도 성립하지 않습니다. 가능일 때는 판정을 확정하는 데 필요한 미지값을 표시합니다.
- `관측 반응 = 실험시계 @ 1080 밀리초`는 미지값의 실제 값을 기록합니다. 조건과 충돌하면 `K404`입니다.
- 미지값이 들어간 `검사`는 모든 해에서 **보장**되어야 통과합니다(`K403`).
- 지원하는 제약은 미지값 하나의 상·하한(`가 <= 값`)과 두 미지값의 차이(`가 - 나 <= 값`)이며, `그리고`로 묶을 수 있습니다. `또는`, `!=`, 미지값의 합이나 배수는 `K405`입니다. 정수 밀리초·밀리미터 단위로 판정하므로 `가 < 나`는 `가 - 나 <= -1`과 같습니다.

### 진단 코드

| 코드 | 의미 |
| --- | --- |
| K100–K101 | 알 수 없는 기호, 한 줄 토큰 수 초과 |
| K200–K201 | 문법 오류, 빈 파일 |
| K301–K304 | 중복 이름, 미선언 참조, 선언 타입 불일치, 연산 타입 불일치 |
| K305 | 기준 위의 점끼리 더함 |
| K306 | 서로 다른 기준의 값을 섞음 |
| K307 | 시각·위치와 시간·거리를 혼동 |
| K308 | `@` 앞이 기준이 아니거나 기준 종류와 값이 맞지 않음 |
| K309 | 기준이나 사건 이름을 값으로 사용 |
| K310–K314 | 사건 역할 중복, 알 수 없는 역할, 필수 역할 누락, 역할 타입 불일치, 읽을 수 없는 역할 |
| K401 | 거짓인 검사 |
| K402 | 사건의 종료가 시작보다 앞섬 |
| K403 | 미지값이 들어간 검사가 모든 해에서 보장되지 않음 |
| K404 | 조건·관측이 서로 모순되거나 항상 거짓 |
| K405 | 지원 범위 밖의 제약(`또는`, `!=`, 미지값의 합·배수·곱) |
| K406 | 정의·사건 역할·관측값에 미지값을 씀 |
| K407 | 미지값이 아닌 이름을 관측하거나 같은 미지값을 두 번 관측 |

## Rust 안전 정책

`Cargo.toml`에서 `unsafe_code = "forbid"`를 설정했습니다. KPL 패키지의 라이브러리, CLI, 테스트에는 `unsafe` 블록, raw pointer 역참조, `unsafe` 함수 호출, 가변 정적 변수 접근을 사용하지 않습니다. Rust 표준 라이브러리와 외부 의존성의 내부 구현은 별도의 범위입니다.
